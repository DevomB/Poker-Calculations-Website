# Board texture

Board texture, scare-card, staticness, and range-board interaction helpers.

| Export | Summary |
| --- | --- |
| [`classifyBoardTexture`](/docs/reference/api/board-texture/classify-board-texture) | Classify a board into a compact texture label. |
| [`boardTextureScore`](/docs/reference/api/board-texture/board-texture-score) | Return pairedness, suitedness, connectedness, wetness, and staticness scores for a board. |
| [`boardWetnessScore`](/docs/reference/api/board-texture/board-wetness-score) | Return a single wetness score for the current board. |
| [`boardPairednessIndex`](/docs/reference/api/board-texture/board-pairedness-index) | Quantify how paired or trips-heavy the board is. |
| [`boardFlushPressure`](/docs/reference/api/board-texture/board-flush-pressure) | Measure suit pressure on a board. |
| [`boardStraightPressure`](/docs/reference/api/board-texture/board-straight-pressure) | Measure rank connectedness and straight pressure on a board. |
| [`boardNutAdvantageApprox`](/docs/reference/api/board-texture/board-nut-advantage-approx) | Approximate nut advantage between two ranges on a board. |
| [`boardRangeInteractionScore`](/docs/reference/api/board-texture/board-range-interaction-score) | Score how strongly a range connects with the board. |
| [`boardStaticnessIndex`](/docs/reference/api/board-texture/board-staticness-index) | Estimate how stable the board is across future runouts. |
| [`boardTurnVolatility`](/docs/reference/api/board-texture/board-turn-volatility) | Score each possible turn card by texture volatility. |
| [`boardRiverScareCardScore`](/docs/reference/api/board-texture/board-river-scare-card-score) | Score a specific river card for scare-card pressure. |
| [`enumerateScareCards`](/docs/reference/api/board-texture/enumerate-scare-cards) | Rank remaining deck cards by scare-card impact. |
| [`boardEquityShiftDistribution`](/docs/reference/api/board-texture/board-equity-shift-distribution) | Summarize how next cards shift range-vs-range board interaction. |
| [`rangeBoardCoverage`](/docs/reference/api/board-texture/range-board-coverage) | Summarize made-hand, draw, overcard, and air coverage for a range on a board. |
| [`heroBoardConnectivityScore`](/docs/reference/api/board-texture/hero-board-connectivity-score) | Score how well hero hole cards connect with the board. |
| [`blockerMatrixByCard`](/docs/reference/api/board-texture/blocker-matrix-by-card) | Return per-card blocker pressure for board and range analysis. |
