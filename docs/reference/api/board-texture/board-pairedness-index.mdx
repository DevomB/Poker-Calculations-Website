# `boardPairednessIndex`
Quantify how paired or trips-heavy the board is.
<div className="apiSignature">{`boardPairednessIndex(board: CardInput): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `boardPairednessIndex` when you need to quantify how paired or trips-heavy the board is.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.boardPairednessIndex(board, range, range);
console.log(result);
```
