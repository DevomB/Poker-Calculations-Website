# `classifyBoardTexture`
Classify a board into a compact texture label.
<div className="apiSignature">{`classifyBoardTexture(board: CardInput): string`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `classifyBoardTexture` when you need to classify a board into a compact texture label.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.classifyBoardTexture(board, range, range);
console.log(result);
```
