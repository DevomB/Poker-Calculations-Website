# `boardNutAdvantageApprox`
Approximate nut advantage between two ranges on a board.
<div className="apiSignature">{`boardNutAdvantageApprox(heroRange: SparseRangeSpec | Float64Array, villainRange: SparseRangeSpec | Float64Array, board: CardInput): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `boardNutAdvantageApprox` when you need to approximate nut advantage between two ranges on a board.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.boardNutAdvantageApprox(board, range, range);
console.log(result);
```
