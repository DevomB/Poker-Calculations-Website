# `heroBoardConnectivityScore`
Score how well hero hole cards connect with the board.
<div className="apiSignature">{`heroBoardConnectivityScore(heroHoleCards: CardInput, board: CardInput): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `heroBoardConnectivityScore` when you need to score how well hero hole cards connect with the board.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.heroBoardConnectivityScore(board, range, range);
console.log(result);
```
