# `boardStraightPressure`
Measure rank connectedness and straight pressure on a board.
<div className="apiSignature">{`boardStraightPressure(board: CardInput, deadCards?: CardInput): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.
## Import
```js
const poker = require('poker-calculations');
```
## ESM (Node)
```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```
## When to use
Use `boardStraightPressure` when building analysis, training, or simulator policy code that needs this calculation directly from the native package.
## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.boardStraightPressure(board, range, range);
console.log(result);
```
