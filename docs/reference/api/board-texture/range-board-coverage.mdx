# `rangeBoardCoverage`
Summarize made-hand, draw, overcard, and air coverage for a range on a board.
<div className="apiSignature">{`rangeBoardCoverage(range: SparseRangeSpec | Float64Array, board: CardInput): RangeCoverageResult`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `rangeBoardCoverage` when you need to summarize made-hand, draw, overcard, and air coverage for a range on a board.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.rangeBoardCoverage(board, range, range);
console.log(result);
```
