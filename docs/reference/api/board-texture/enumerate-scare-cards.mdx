# `enumerateScareCards`
Rank remaining deck cards by scare-card impact.
<div className="apiSignature">{`enumerateScareCards(board: CardInput, rangeA: SparseRangeSpec | Float64Array, rangeB: SparseRangeSpec | Float64Array): CardScore[]`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `enumerateScareCards` when you need to rank remaining deck cards by scare-card impact.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.enumerateScareCards(board, range, range);
console.log(result);
```
