# `boardTextureScore`
Return pairedness, suitedness, connectedness, wetness, and staticness scores for a board.
<div className="apiSignature">{`boardTextureScore(board: CardInput): BoardTextureResult`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `boardTextureScore` when you need to return pairedness, suitedness, connectedness, wetness, and staticness scores for a board.

## How to use
```js
const poker = require('poker-calculations');
const board = ['Qh', 'Jh', '2c'];
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.boardTextureScore(board, range, range);
console.log(result);
```
