# Side-pot breakeven

<ApiFamilyHeader category="Side pots" suit="♣" functions={["sidePotBreakevenCallEquity"]} />

## `sidePotBreakevenCallEquity` \{#sidePotBreakevenCallEquity\}
Breakeven equity for hero side-pot layer.

```ts
sidePotBreakevenCallEquity(layerPotChips: number, toCall: number): number;
```

Breakeven equity for a call into a **single layer** pot: `toCall / (layerPot + toCall)`.

```js title="Example"
const poker = require('poker-calculations');

const layerPot = 150;
const toCall = 50;

console.log(poker.sidePotBreakevenCallEquity(layerPot, toCall)); // 50/200
```

```text title="Output"
0.25
```
