# Side-pot ladder

<ApiFamilyHeader category="Side pots" suit="♣" functions={["sidePotLadderFromCommitments","sidePotLayersTotalChips","sidePotLayerCount"]} />

## `sidePotLadderFromCommitments` \{#sidePotLadderFromCommitments\}

Main pot and side pots from each player's total commitment: one layer per distinct positive commitment level, holding `level − previous level` from every player who reached that level (exact comparisons, so the layers add up to the commitments and a player with nothing in contributes to nothing). A top layer with a single contributor is an uncalled excess returned to that player. Folded players' chips are included; who may win each layer is up to the caller.

```ts
sidePotLadderFromCommitments(committedChips: F64VectorInput): SidePotLayer[];
```

<details>
<summary>Types: <code>SidePotLayer</code></summary>

```ts
interface SidePotLayer {
  potChips: number;
  playerCapContribution: number[];
}
```

Field notes: [`SidePotLayer`](/docs/reference/types/side-pot-layer)

</details>

All-in side pots: pass each player’s **total chips committed** this hand to get ordered layers `{ potChips, playerCapContribution[] }`. Feed layers into equity-by-layer EV or display pot breakdown UIs.

This is exact chip accounting. Commitments are compared exactly; before 4.2.0 an absolute 1e-12 tolerance could create chips (`[1e-13, 2e-13]` totalled 4e-13) and count a player who had nothing in. Now `[1e-13, 2e-13]` gives a 2e-13 layer for both players and a 1e-13 layer for the second player alone, 3e-13 in total.

```js title="Example"
const poker = require('poker-calculations');

const committed = [100, 300, 300, 50]; // seat 0 short, seat 3 shorter
const layers = poker.sidePotLadderFromCommitments(committed);
console.log(layers);

console.log(poker.sidePotLayersTotalChips(layers));
```

```text title="Output"
[
  { potChips: 200, playerCapContribution: [ 50, 50, 50, 50 ] },
  { potChips: 150, playerCapContribution: [ 50, 50, 50, 0 ] },
  { potChips: 400, playerCapContribution: [ 0, 200, 200, 0 ] }
]
750
```

## `sidePotLayersTotalChips` \{#sidePotLayersTotalChips\}

Sum of `potChips` over side-pot layers.

```ts
sidePotLayersTotalChips(layers: SidePotLayer[]): number;
```

Quick **total chips in play** across main and side pots after building a ladder—sanity checks, pot display, and comparing to table `pot` field before EV attribution.

```js title="Example"
const poker = require('poker-calculations');

const layers = poker.sidePotLadderFromCommitments([200, 500, 500, 100]);
const total = poker.sidePotLayersTotalChips(layers);
console.log('total in all layers:', total);

layers.forEach((layer, i) => {
  console.log(`layer ${i}:`, layer.potChips);
});
```

```text title="Output"
total in all layers: 1300
layer 0: 400
layer 1: 300
layer 2: 600
```

## `sidePotLayerCount` \{#sidePotLayerCount\}

Number of side-pot layers.

```ts
sidePotLayerCount(committedChips: F64VectorInput): number;
```

Number of side-pot layers from committed chip counts — same as `sidePotLadderFromCommitments(...).length`. In the example, `[100, 200, 500]` gives a 300 main pot, a 200 side pot between seats 1 and 2, and 300 that only seat 2 put in: that top layer is the uncalled excess returned to seat 2.

```js title="Example"
const poker = require('poker-calculations');

const committed = [100, 200, 500];
const layers = poker.sidePotLadderFromCommitments(committed);
console.log(poker.sidePotLayerCount(committed), layers.length);
```

```text title="Output"
3 3
```
