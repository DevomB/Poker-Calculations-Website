# `exactEquityRealizationEstimate`
Estimate realized equity from exact equity, position, SPR, and board staticness.
<div className="apiSignature">{`exactEquityRealizationEstimate(heroHoleCards: CardInput, boardCards: CardInput, villainRange: SparseRangeSpec | Float64Array, position: string, spr: number): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `exactEquityRealizationEstimate` when you need to estimate realized equity from exact equity, position, SPR, and board staticness.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.exactEquityRealizationEstimate(['Ah', 'Kh'], ['Qh', 'Jh', '2c'], range, 0.5);
console.log(result);
```
