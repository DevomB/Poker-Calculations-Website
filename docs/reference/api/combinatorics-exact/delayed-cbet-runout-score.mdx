# `delayedCbetRunoutScore`
Score turn cards for delayed continuation-bet potential.
<div className="apiSignature">{`delayedCbetRunoutScore(heroRange: SparseRangeSpec | Float64Array, villainRange: SparseRangeSpec | Float64Array, flop: CardInput): Float64Array`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `delayedCbetRunoutScore` when you need to score turn cards for delayed continuation-bet potential.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.delayedCbetRunoutScore(['Ah', 'Kh'], ['Qh', 'Jh', '2c'], range, 0.5);
console.log(result);
```
