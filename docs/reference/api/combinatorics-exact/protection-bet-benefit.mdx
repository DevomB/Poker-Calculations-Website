# `protectionBetBenefit`
Estimate the chip value of protection from a bet.
<div className="apiSignature">{`protectionBetBenefit(heroHoleCards: CardInput, boardCards: CardInput, villainRange: SparseRangeSpec | Float64Array, betSize: number): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `protectionBetBenefit` when you need to estimate the chip value of protection from a bet.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.protectionBetBenefit(['Ah', 'Kh'], ['Qh', 'Jh', '2c'], range, 0.5);
console.log(result);
```
