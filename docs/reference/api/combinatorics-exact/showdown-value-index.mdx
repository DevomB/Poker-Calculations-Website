# `showdownValueIndex`
Estimate check-down showdown value versus a villain range.
<div className="apiSignature">{`showdownValueIndex(heroHoleCards: CardInput, boardCards: CardInput, villainRange: SparseRangeSpec | Float64Array): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `showdownValueIndex` when you need to estimate check-down showdown value versus a villain range.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.showdownValueIndex(['Ah', 'Kh'], ['Qh', 'Jh', '2c'], range, 0.5);
console.log(result);
```
