# `equityRealizationPenalty`
Compute a realization discount from position, SPR, and board staticness.
<div className="apiSignature">{`equityRealizationPenalty(equity: number, position: string, spr: number, boardStaticness: number): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.
## Import
```js
const poker = require('poker-calculations');
```
## ESM (Node)
```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```
## When to use
Use `equityRealizationPenalty` when building analysis, training, or simulator policy code that needs this calculation directly from the native package.
## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.equityRealizationPenalty(['Ah', 'Kh'], ['Qh', 'Jh', '2c'], range, 0.5);
console.log(result);
```
