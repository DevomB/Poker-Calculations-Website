# Odds display

## `formatPotOdds` \{#formatPotOdds\}
Human-readable `"x:1"` string.

```ts
formatPotOdds(potBeforeCall: number, toCall: number, decimals?: number): string;
```

Render pot odds in the UI without hand-formatting floats. Optional `decimals` controls rounding of the leading number in the `x:1` display.

```js title="Example"
const poker = require('poker-calculations');
console.log(poker.formatPotOdds(175, 50));    // '3.50:1'
console.log(poker.formatPotOdds(175, 50, 0)); // '4:1' with 0 decimals
console.log(poker.formatPotOdds(175, 0));     // nothing to call
```

```text title="Output"
3.50:1
4:1
∞:1
```

## `potOddsRatioDisplay` \{#potOddsRatioDisplay\}
Display ratio `pot : to_call` (e.g. `3.5` means 3.5:1).

```ts
potOddsRatioDisplay(potBeforeCall: number, toCall: number): number;
```

Present pot odds the way players say them aloud—**pot divided by price to call**. Pair with `breakevenCallEquityFromPotOddsDisplayRatio` for equity thresholds, or `formatPotOdds` for strings.

```js title="Example"
const poker = require('poker-calculations');

const pot = 140;
const toCall = 40;
const r = poker.potOddsRatioDisplay(pot, toCall);
console.log(r); // 3.5 → "3.5:1"

const be = poker.breakevenCallEquityFromPotOddsDisplayRatio(r);
console.log(be);
```

```text title="Output"
3.5
0.2222222222222222
```

## `formatPotOddsReducedFraction` \{#formatPotOddsReducedFraction\}
Reduced integer `pot : to_call` string (e.g. `100`, `50` → `"2:1"`); `toCall === 0` → `∞:1`.

```ts
formatPotOddsReducedFraction(potBeforeCall: number, toCall: number): string;
```

Use to show **human-readable pot odds** in UIs, flashcards, or logs after rounding real chip amounts. Unlike decimal `formatPotOdds`, this gcd-reduces rounded integers so `100`/`50` becomes `2:1` instead of `2.00:1`.

```js title="Example"
const poker = require('poker-calculations');

console.log(poker.formatPotOddsReducedFraction(100, 50)); // "2:1"
console.log(poker.formatPotOddsReducedFraction(90, 30)); // "3:1"
console.log(poker.formatPotOddsReducedFraction(200, 0)); // "∞:1"

// From breakeven equity → display ratio → label
const ratio = poker.potOddsDisplayRatioFromBreakevenCallEquity(0.25);
const label = poker.formatPotOddsReducedFraction(300, 100);
console.log({ ratio, label });
```

```text title="Output"
2:1
3:1
∞:1
{ ratio: 3, label: '3:1' }
```

**Returns** `string` — reduced `"p:c"` (e.g. `100`, `50` → `"2:1"`). When `toCall === 0`, `"∞:1"`. Chip inputs are rounded to integers before gcd; throws if rounded `toCall` is not positive.

## `breakevenCallEquityFromPotOddsDisplayRatio` \{#breakevenCallEquityFromPotOddsDisplayRatio\}
Breakeven call equity from `potOddsRatioDisplay` ratio `R = potBeforeCall / toCall`: `1 / (1 + R)`. `0` when `R` is `+Infinity`.

```ts
breakevenCallEquityFromPotOddsDisplayRatio(displayPotToCallRatio: number): number;
```

Use when your UI or notes already express odds as **pot : call** (e.g. user entered “2:1” meaning the pot is twice the call) and you need the equity threshold without re-entering chip counts. Inverse of [`potOddsDisplayRatioFromBreakevenCallEquity`](/docs/reference/api/pot-odds-and-ev/odds-display#potOddsDisplayRatioFromBreakevenCallEquity).

```js title="Example"
const poker = require('poker-calculations');

// Villain offers 2:1 — pot before your call is twice what you must put in
const displayRatio = 2; // potBeforeCall / toCall
const need = poker.breakevenCallEquityFromPotOddsDisplayRatio(displayRatio);
console.log(need); // 1 / (1 + 2) ≈ 0.333...

// Same threshold from chips
const fromChips = poker.breakevenCallEquity(100, 50);
console.log(fromChips);

// Free call line (R = +Infinity) → 0
console.log(
  poker.breakevenCallEquityFromPotOddsDisplayRatio(Number.POSITIVE_INFINITY),
);
```

```text title="Output"
0.3333333333333333
0.3333333333333333
0
```

**Returns** `number` — `1 / (1 + R)` for finite non-negative `R`; `0` when `R` is `+Infinity`. Throws if `R` is invalid (negative finite, NaN, etc.).

## `potOddsDisplayRatioFromBreakevenCallEquity` \{#potOddsDisplayRatioFromBreakevenCallEquity\}
Inverse of `breakevenCallEquityFromPotOddsDisplayRatio`: `(1 - e) / e` for `e` in `(0,1]`; `Infinity` when `e === 0`; `0` when `e === 1`.

```ts
potOddsDisplayRatioFromBreakevenCallEquity(breakevenEquity: number): number;
```

Use when a solver or quiz gives you a **minimum equity** (e.g. “need 20%”) and you want the familiar **X:1** pot-odds label (`potBeforeCall / toCall`), or to rebuild chip labels via `formatPotOddsReducedFraction` after you pick a call size.

```js title="Example"
const poker = require('poker-calculations');

const need = 0.25; // 25% breakeven
const displayRatio = poker.potOddsDisplayRatioFromBreakevenCallEquity(need);
console.log(displayRatio); // 3 — read as 3:1

const toCall = 30;
const potBeforeCall = displayRatio * toCall; // 90
console.log(poker.formatPotOddsReducedFraction(potBeforeCall, toCall)); // "3:1"

// Round-trip check
const back = poker.breakevenCallEquityFromPotOddsDisplayRatio(displayRatio);
console.log(back); // 0.25
```

```text title="Output"
3
3:1
0.25
```

**Returns** `number` — `(1 − e) / e` for `e` in `(0, 1]`; `Infinity` when `e === 0`; `0` when `e === 1`. Input equity is clamped to `[0, 1]`.

## `equityToWinningOddsAgainst` \{#equityToWinningOddsAgainst\}
Book-style winning odds-against `(1 - equity) / equity`; `Infinity` at `equity === 0`.

```ts
equityToWinningOddsAgainst(equity: number): number;
```

Use when a study tool or book quote gives **equity** but you want “3:1 against” style numbers (lose : win), or to label draw strength next to pot-odds display ratios. Pair with [`winningOddsAgainstToEquity`](/docs/reference/api/pot-odds-and-ev/odds-display#winningOddsAgainstToEquity) to round-trip.

```js title="Example"
const poker = require('poker-calculations');

const equity = 0.25; // 25% to win
const against = poker.equityToWinningOddsAgainst(equity);
console.log(against); // 3 — often read as "3:1 against"

// Round-trip
const back = poker.winningOddsAgainstToEquity(against);
console.log(back); // 0.25

console.log(poker.equityToWinningOddsAgainst(0)); // Infinity
console.log(poker.equityToWinningOddsAgainst(1)); // 0
```

```text title="Output"
3
0.25
Infinity
0
```

Not the same as **pot** odds (`potBeforeCall / toCall`); this is purely equity ↔ book odds.

**Returns** `number` — `(1 − equity) / equity` for equity in `(0, 1)`; `Infinity` at `equity === 0`; `0` at `equity === 1`. Input is clamped to `[0, 1]`.

## `winningOddsAgainstToEquity` \{#winningOddsAgainstToEquity\}
`1 / (1 + oddsAgainst)` for `oddsAgainst >= 0`; `0` when `oddsAgainst` is `+Infinity`.

```ts
winningOddsAgainstToEquity(oddsAgainst: number): number;
```

Use when the user or a book states **odds against** (e.g. “4:1 against” → `oddsAgainst = 4`) and you need equity for comparison to [`breakevenCallEquity`](/docs/reference/api/pot-odds-and-ev/pot-odds#breakevenCallEquity) or [`expectedValueCall`](/docs/reference/api/pot-odds-and-ev/expected-value-call#expectedValueCall).

```js title="Example"
const poker = require('poker-calculations');

const oddsAgainst = 3; // 3:1 against → 25% equity
const equity = poker.winningOddsAgainstToEquity(oddsAgainst);
console.log(equity); // 0.25

// Match equityToWinningOddsAgainst
const again = poker.equityToWinningOddsAgainst(equity);
console.log(again); // 3

// Impossible win line
console.log(poker.winningOddsAgainstToEquity(Number.POSITIVE_INFINITY)); // 0
```

```text title="Output"
0.25
3
0
```

**Returns** `number` — `1 / (1 + oddsAgainst)` for non-negative finite `oddsAgainst`; `0` when `oddsAgainst` is `+Infinity`. Throws if `oddsAgainst` is invalid (negative finite, NaN, etc.).
