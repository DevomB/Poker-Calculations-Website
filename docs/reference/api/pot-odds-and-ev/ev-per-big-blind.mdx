# EV in big blinds

<ApiFamilyHeader category="Pot odds & EV" suit="♥" functions={["expectedValuePerBigBlind"]} />

## `expectedValuePerBigBlind` \{#expectedValuePerBigBlind\}
Chip EV expressed in big blinds.

```ts
expectedValuePerBigBlind(chipEv: number, bigBlind: number): number;
```

Express chip EV in big-blind units for HUDs and session summaries.

```js title="Example"
const poker = require('poker-calculations');

const chipEv = 24;
const bigBlind = 2;

console.log(poker.expectedValuePerBigBlind(chipEv, bigBlind)); // 12 bb
```

```text title="Output"
12
```
