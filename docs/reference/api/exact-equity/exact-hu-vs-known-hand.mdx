# Heads-up vs a known hand

<ApiFamilyHeader category="Exact equity" suit="♦" functions={["exactHuEquityVsKnownHand"]} />

## `exactHuEquityVsKnownHand` \{#exactHuEquityVsKnownHand\}

Exact HU vs known villain hole cards; board empty (preflop) or 3–5 cards.

```ts
exactHuEquityVsKnownHand(
  heroHoleCards: CardInput,
  villainHoleCards: CardInput,
  boardCards: CardInput
): number;
```

Use for hand-vs-hand analysis on the flop, turn, or river, or preflop with an empty board (enumerates all runouts). Every card must be distinct across hero, villain, and the board; a duplicate, including two identical villain cards, throws (before 4.2.0 a duplicate villain card was accepted).

```js title="Example"
const poker = require('poker-calculations');

const equity = poker.exactHuEquityVsKnownHand(
  ['Ah', 'Kd'],
  ['Qc', 'Qs'],
  ['Jh', 'Tc', '2d'],
);
console.log(equity);
```

```text title="Output"
0.2868686868686869
```
