# Equity quantiles

<ApiFamilyHeader category="Runout analysis" suit="♣" functions={["exactHeroEquityRunoutQuantiles","exactHeroEquityRunoutQuantilesAsync"]} />

## `exactHeroEquityRunoutQuantiles` \{#exactHeroEquityRunoutQuantiles\}

Exact **distribution** of hero equity over all turn/river runouts — mean, variance, and p05/p50/p95 — vs a random villain or an optional weighted range.

```ts
exactHeroEquityRunoutQuantiles(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range?: Float64Array | SparseRangeSpec
): HeroEquityRunoutQuantilesResult;
```

<details>
<summary>Types: <code>HeroEquityRunoutQuantilesResult</code></summary>

```ts
interface HeroEquityRunoutQuantilesResult {
  mean: number;
  variance: number;
  p05: number;
  p50: number;
  p95: number;
  n: number;
}
```

Field notes: [`HeroEquityRunoutQuantilesResult`](/docs/reference/types/hero-equity-runout-quantiles-result)

</details>

Mean equity on a draw-heavy board hides bad runouts — enumerate all completions and read the **spread** (tail risk, variance) for study or bot thresholds.

```js title="Example"
const poker = require('poker-calculations');

const hero = ['Ah', 'Kh'];
const flop = ['Qh', 'Jh', '2c'];

const q = poker.exactHeroEquityRunoutQuantiles(hero, flop);

console.log('Mean:', q.mean);
console.log('p05 / p50 / p95:', q.p05, q.p50, q.p95);
console.log('Runouts:', q.n);
```

```text title="Output"
Mean: 0.7633009091843457
p05 / p50 / p95: 0.36414141414141415 0.8767676767676768 1
Runouts: 1081
```

Omit `range` for equity vs a uniform random villain: every runout is equally likely. Pass `Float64Array(1326)` or a sparse spec for a weighted range (heavier); the statistics are then **predictive**. Villain's range makes some boards likelier (the cards villain holds cannot come), so each runout is weighted by the range mass that does not use its cards, runouts that no combo can coexist with are skipped, and `mean` equals [`exactHuEquityVsRange`](/docs/reference/api/exact-equity/exact-hu-vs-range#exactHuEquityVsRange) on the current board. Quantiles interpolate the weighted distribution (equal weights give the usual `q·(n − 1)` interpolation). The board must be a **3-card flop**: any other length throws (the async form rejects), since preflop and partial-flop boards are not enumerated.

```js title="Example"
const poker = require('poker-calculations');

const hero = ['Ah', 'Ad'];
const flop = ['2c', '7d', '9s'];
// KhKd once, 9c9d nine times as often, 3c4d once.
const range = { indices: [45, 46, 28, 29, 4, 9], weights: [1, 9, 1] };

const q = poker.exactHeroEquityRunoutQuantiles(hero, flop, range);
console.log('Mean:', q.mean);
console.log('Direct equity:', poker.exactHuEquityVsRange(hero, flop, range));
console.log('Possible runouts:', q.n);
```

```text title="Output"
Mean: 0.24086317722681358
Direct equity: 0.24086317722681358
Possible runouts: 1081
```

**Returns** [`HeroEquityRunoutQuantilesResult`](/docs/reference/types/hero-equity-runout-quantiles-result).

## `exactHeroEquityRunoutQuantilesAsync` \{#exactHeroEquityRunoutQuantilesAsync\}

Non-blocking [`exactHeroEquityRunoutQuantiles`](/docs/reference/api/runout-analysis/runout-equity-quantiles#exactHeroEquityRunoutQuantiles) — same runout equity distribution with optional `AbortSignal`.

```ts
exactHeroEquityRunoutQuantilesAsync(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range?: Float64Array | SparseRangeSpec,
  options?: AsyncOptions
): Promise<HeroEquityRunoutQuantilesResult>;
```

<details>
<summary>Types: <code>HeroEquityRunoutQuantilesResult</code></summary>

```ts
interface HeroEquityRunoutQuantilesResult {
  mean: number;
  variance: number;
  p05: number;
  p50: number;
  p95: number;
  n: number;
}
```

Field notes: [`HeroEquityRunoutQuantilesResult`](/docs/reference/types/hero-equity-runout-quantiles-result)

</details>

Same as sync (including the predictive weighting with a range), for a **weighted villain range** or when enumeration would block the server — use `await` and optional cancellation.

```js title="Example"
const poker = require('poker-calculations');

const range = new Float64Array(1326);
range.fill(1 / 1326);

const q = await poker.exactHeroEquityRunoutQuantilesAsync(
  ['Ah', 'Kh'],
  ['Qh', 'Jh', '2c'],
  range,
);

console.log('Mean:', q.mean, 'p05:', q.p05, 'p95:', q.p95);
```

```text title="Output"
Mean: 0.7633009091843473 p05: 0.36414141414141427 p95: 1
```

**Returns** [`HeroEquityRunoutQuantilesResult`](/docs/reference/types/hero-equity-runout-quantiles-result).
