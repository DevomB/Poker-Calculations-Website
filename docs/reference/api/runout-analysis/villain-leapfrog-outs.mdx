# Villain leapfrog outs

<ApiFamilyHeader category="Runout analysis" suit="♣" functions={["exactVillainLeapfrogOutCounts"]} />

## `exactVillainLeapfrogOutCounts` \{#exactVillainLeapfrogOutCounts\}

Deck indices where the **next board card** leapfrogs villain ahead of hero, and where hero's strength **improves** vs the current board.

```ts
exactVillainLeapfrogOutCounts(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  knownDead?: CardInput
): VillainLeapfrogOutCountsResult;
```

<details>
<summary>Types: <code>VillainLeapfrogOutCountsResult</code></summary>

```ts
interface VillainLeapfrogOutCountsResult {
  leapfrogDeckIndices: number[];
  heroImproveDeckIndices: number[];
}
```

Field notes: [`VillainLeapfrogOutCountsResult`](/docs/reference/types/villain-leapfrog-out-counts-result)

</details>

You want **anti-out** and **hero-improve** card lists on a flop or turn — for study overlays, blocker charts, or exact out counting without Monte Carlo.

```js title="Example"
const poker = require('poker-calculations');
const { deckIndexToCardString } = require('poker-calculations/encode');

const { leapfrogDeckIndices, heroImproveDeckIndices } =
  poker.exactVillainLeapfrogOutCounts(['Ah', 'Kh'], ['Qh', 'Jh', '2c']);

const leapfrogCards = leapfrogDeckIndices.map(deckIndexToCardString);
console.log('Leapfrog outs:', leapfrogCards);
console.log('Hero improve count:', heroImproveDeckIndices.length);
```

```text title="Output"
Leapfrog outs: [
  '2d', '2h', '2s', '3c', '3d', '3s',
  '4c', '4d', '4s', '5c', '5d', '5s',
  '6c', '6d', '6s', '7c', '7d', '7s',
  '8c', '8d', '8h', '8s', '9c', '9d',
  '9h', '9s', 'Jc', 'Jd', 'Js', 'Qc',
  'Qd', 'Qs', 'Kc', 'Kd', 'Ks', 'Ac',
  'Ad', 'As'
]
Hero improve count: 47
```

`boardCards` must have **3 or 4** cards.

**Returns** [`VillainLeapfrogOutCountsResult`](/docs/reference/types/villain-leapfrog-out-counts-result).
