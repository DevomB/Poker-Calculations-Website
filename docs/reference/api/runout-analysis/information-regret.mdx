# Information regret

<ApiFamilyHeader category="Runout analysis" suit="♣" functions={["exactInformationRegretVsClairvoyant"]} />

## `exactInformationRegretVsClairvoyant` \{#exactInformationRegretVsClairvoyant\}

Chip EV gap between **clairvoyant** play (seeing the final runout) and **realistic** call/fold EV on the current board against a weighted range.

```ts
exactInformationRegretVsClairvoyant(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range: Float64Array | SparseRangeSpec,
  potBeforeCall: number,
  toCall: number
): number;
```

You want to quantify **information regret** on one street — how many chips hero gives up by not knowing the runout when facing a call decision vs a weighted villain range.

```js title="Example"
const poker = require('poker-calculations');

const range = new Float64Array(1326);
range.fill(1 / 1326);

const regret = poker.exactInformationRegretVsClairvoyant(
  ['Ah', 'Kh'],
  ['Qh', 'Jh', '2c'],
  range,
  100,
  50,
);

console.log('EV gap (chips):', regret);
```

```text title="Output"
EV gap (chips): 0.06026967007892381
```

Both sides pick the better of calling and folding (EV 0): hero now, with its equity on the current board, and a clairvoyant who first sees the rest of the board. The result is the average over runouts of `max(0, callEV)` minus `max(0, callEV)` now, with runouts weighted by their probability given the range (the range mass that does not use their cards), so the clairvoyant's average equity equals hero's equity now. It is never negative, 0 on the river, and 0 when no runout makes the call profitable. `potBeforeCall` (villain's bet included) and `toCall` are the pot and call size when hero acts; the board may have 3, 4, or 5 cards.

**Returns** Scalar `number` — chip EV difference (clairvoyant minus realistic optimal).
