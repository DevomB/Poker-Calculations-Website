# Semi-bluff

<ApiFamilyHeader category="GTO & fold equity" suit="♣" functions={["breakevenFoldEquitySemiBluff","breakevenFoldEquitySemiBluffWithRake","breakevenFoldEquitySemiBluffWithAnte"]} />

## `breakevenFoldEquitySemiBluff` \{#breakevenFoldEquitySemiBluff\}

Two-outcome model; may exceed 1 if line is −EV even if villain always folds.

```ts
breakevenFoldEquitySemiBluff(
  potBeforeHeroBet: number,
  heroBetSize: number,
  equityWhenCalled: number,
  totalPotIfCalled: number
): number;
```

Semi-bluffs: you win the pot when villain folds and have **nonzero equity** when called. Pass equity when called and the total pot size if called (including your bet). Result can exceed `1` if the line is losing even when villain always folds.

```js title="Example"
const poker = require('poker-calculations');
const pot = 80;
const bet = 55;
const equityWhenCalled = 0.2;
const totalPotIfCalled = pot + 2 * bet; // 190

// Fold equity at which the semi-bluff breaks even. At 32%+ equity it is +EV even when always called.
console.log(poker.breakevenFoldEquitySemiBluff(pot, bet, equityWhenCalled, totalPotIfCalled).toFixed(3));
```

```text title="Output"
0.175
```

## `breakevenFoldEquitySemiBluffWithRake` \{#breakevenFoldEquitySemiBluffWithRake\}

Semi-bluff breakeven fold equity with rake on both outcomes.

```ts
breakevenFoldEquitySemiBluffWithRake(
  potBeforeHeroBet: number,
  heroBetSize: number,
  equityWhenCalled: number,
  totalPotIfCalled: number,
  rakeFraction: number,
  rakeCap: number
): number;
```

Uses the payouts of [`expectedValueRaiseWithRake`](/docs/reference/api/pot-odds-and-ev/expected-value-raise#expectedValueRaiseWithRake): a fold wins `potBeforeHeroBet − rake(potBeforeHeroBet + heroBetSize)`, a call pays `equityWhenCalled × (totalPotIfCalled − rake(totalPotIfCalled)) − heroBetSize`. The result is the fold equity at which that EV is 0, and 0 when the called branch alone is profitable. For pot 100, bet 50, 10% equity when called, final pot 200, and 5% rake, the threshold is `31 / 123.5 ≈ 25.10%`.

```js title="Example"
const poker = require('poker-calculations');

const fe = poker.breakevenFoldEquitySemiBluffWithRake(
  90,
  60,
  0.28,
  90 + 2 * 60,
  0.05,
  5
);
console.log(fe);

const noRake = poker.breakevenFoldEquitySemiBluff(90, 60, 0.28, 210);
console.log('without rake:', noRake);

// The raise EV with rake is 0 at the threshold.
console.log('EV at threshold:', poker.expectedValueRaiseWithRake(0.28, 90, 60, fe, 210, 0.05, 5).toFixed(9));
```

```text title="Output"
0.02968036529680359
without rake: 0.01315789473684206
EV at threshold: 0.000000000
```

## `breakevenFoldEquitySemiBluffWithAnte` \{#breakevenFoldEquitySemiBluffWithAnte\}

Semi-bluff fold equity with ante.

```ts
breakevenFoldEquitySemiBluffWithAnte(
  potBeforeHeroBet: number,
  heroBetSize: number,
  equityWhenCalled: number,
  totalPotIfCalled: number,
  anteToPost: number
): number;
```

Semi-bluff breakeven fold equity with ante in the won-pot model.

```js title="Example"
const poker = require('poker-calculations');

const fe = poker.breakevenFoldEquitySemiBluffWithAnte(
  100, 50,
  0.35,  // equity when called
  200,   // total pot if called
  5,     // ante
);
console.log(fe);
```

```text title="Output"
0
```
