# Minimum defense frequency

<ApiFamilyHeader category="GTO & fold equity" suit="♣" functions={["minimumDefenseFrequency","alphaFrequency","minimumDefenseFrequencyWithRake","alphaFrequencyWithRake"]} />

## `minimumDefenseFrequency` \{#minimumDefenseFrequency\}

**MDF** from pot geometry before the opponent’s bet: `potBeforeOpponentBet / (potBeforeOpponentBet + opponentBetSize)`. Complements [`alphaFrequency`](/docs/reference/api/gto-and-fold-equity/minimum-defense-frequency#alphaFrequency) (`1 - MDF`).

```ts
minimumDefenseFrequency(potBeforeOpponentBet: number, opponentBetSize: number): number;
```

Use when a villain bets into a pot and you need the **minimum defend frequency** that makes their bluffs break even—study charts, GTO trainers, or quick MDF labels.

```js title="Example"
const poker = require('poker-calculations');

const mdf = poker.minimumDefenseFrequency(100, 50);
// 100/150 — hero must defend at least this fraction vs a pure bluff
console.log(mdf + poker.alphaFrequency(100, 50)); // 1
```

```text title="Output"
1
```

## `alphaFrequency` \{#alphaFrequency\}

`1 - minimumDefenseFrequency` = `bet / (pot + bet)`.

```ts
alphaFrequency(potBeforeBet: number, betSize: number): number;
```

**Alpha** is how often villain must fold for a pure bluff to break even if you never get called. Teaching tools pair alpha with estimated fold frequency from population stats.

```js title="Example"
const poker = require('poker-calculations');

const pot = 80;
const bet = 60;

const alpha = poker.alphaFrequency(pot, bet);
const mdf = poker.minimumDefenseFrequency(pot, bet);
console.log(alpha, mdf, alpha + mdf); // alpha + mdf = 1

const beFe = poker.breakevenFoldEquityPureBluff(pot, bet);
console.log('breakeven FE (pure bluff):', beFe);
```

```text title="Output"
0.42857142857142855 0.5714285714285714 1
breakeven FE (pure bluff): 0.42857142857142855
```

## `minimumDefenseFrequencyWithRake` \{#minimumDefenseFrequencyWithRake\}

MDF on post-rake pot geometry.

```ts
minimumDefenseFrequencyWithRake(
  potBeforeBet: number,
  betSize: number,
  rakeFraction: number,
  rakeCap: number
): number;
```

MDF on **post-rake** pot geometry after villain bets. At least as high as [`minimumDefenseFrequency`](/docs/reference/api/gto-and-fold-equity/minimum-defense-frequency#minimumDefenseFrequency) without rake.

```js title="Example"
const poker = require('poker-calculations');

const potBeforeBet = 100;
const betSize = 50;
const rakeFraction = 0.05;
const rakeCap = 3;

const mdf = poker.minimumDefenseFrequencyWithRake(
  potBeforeBet,
  betSize,
  rakeFraction,
  rakeCap,
);
const mdf0 = poker.minimumDefenseFrequency(potBeforeBet, betSize);
console.log({ mdf, mdf0 });
```

```text title="Output"
{ mdf: 0.6598639455782312, mdf0: 0.6666666666666666 }
```

## `alphaFrequencyWithRake` \{#alphaFrequencyWithRake\}

`1 − MDF` with rake model.

```ts
alphaFrequencyWithRake(
  potBeforeBet: number,
  betSize: number,
  rakeFraction: number,
  rakeCap: number
): number;
```

Bluff frequency complement with rake: `1 − MDF_with_rake`.

```js title="Example"
const poker = require('poker-calculations');

const potBeforeBet = 100;
const betSize = 50;
const rakeFraction = 0.05;
const rakeCap = 3;

const mdf = poker.minimumDefenseFrequencyWithRake(
  potBeforeBet,
  betSize,
  rakeFraction,
  rakeCap,
);
const alpha = poker.alphaFrequencyWithRake(potBeforeBet, betSize, rakeFraction, rakeCap);
console.log(mdf + alpha); // 1
```

```text title="Output"
1
```
