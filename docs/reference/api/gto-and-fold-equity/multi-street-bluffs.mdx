## `twoStreetPureBluffEv` \{#twoStreetPureBluffEv\}

EV of two-street pure bluff with independent `fe1`, `fe2`.

```ts
twoStreetPureBluffEv(
  potBeforeStreet1: number,
  betStreet1: number,
  betStreet2: number,
  foldEquityStreet1: number,
  foldEquityStreet2: number
): number;
```

```js title="Example"
const poker = require('poker-calculations');

const ev = poker.twoStreetPureBluffEv(
  60,  // pot before flop bet
  40,  // flop bet
  110, // turn bet
  0.45,
  0.38
);
console.log('two-street bluff EV:', ev);

const fe2 = poker.breakevenFoldEquitySecondStreetPureBluff(60, 40, 110, 0.45);
console.log('breakeven turn FE if flop FE=45%:', fe2);
```

```text title="Output"
two-street bluff EV: -3.2500000000000036
breakeven turn FE if flop FE=45%: 0.4036363636363636
```

## `twoStreetPureBluffEvWithRake` \{#twoStreetPureBluffEvWithRake\}

Two-street air EV with rake.

```ts
twoStreetPureBluffEvWithRake(
  potBeforeStreet1: number,
  betStreet1: number,
  betStreet2: number,
  foldEquityStreet1: number,
  foldEquityStreet2: number,
  rakeFraction: number,
  rakeCap: number
): number;
```

```js title="Example"
const poker = require('poker-calculations');

const ev = poker.twoStreetPureBluffEvWithRake(
  60, 40, 110,
  0.45, 0.38,
  0.05, 3,
);
const ev0 = poker.twoStreetPureBluffEv(60, 40, 110, 0.45, 0.38);
console.log({ ev, ev0 });
```

```text title="Output"
{ ev: -5.227000000000004, ev0: -3.2500000000000036 }
```

## `twoStreetPureBluffSameFoldEquity` \{#twoStreetPureBluffSameFoldEquity\}

same FE both streets, pure air; may return NaN if no root in [0,1].

```ts
twoStreetPureBluffSameFoldEquity(
  potBeforeStreet1: number,
  betStreet1: number,
  betStreet2: number
): number;
```

```js title="Example"
const poker = require('poker-calculations');

const pot0 = 50;
const bet1 = 35;
const bet2 = 90;

const fe = poker.twoStreetPureBluffSameFoldEquity(pot0, bet1, bet2);
console.log('breakeven FE each street:', fe);

if (!Number.isNaN(fe)) {
  console.log(poker.twoStreetPureBluffEv(pot0, bet1, bet2, fe, fe));
}
```

```text title="Output"
breakeven FE each street: 0.42165183604067163
-7.105427357601002e-15
```

## `breakevenFoldEquityFirstStreetPureBluff` \{#breakevenFoldEquityFirstStreetPureBluff\}

0
