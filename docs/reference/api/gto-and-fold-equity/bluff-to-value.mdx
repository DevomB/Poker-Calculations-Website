# Bluff-to-value ratio

<ApiFamilyHeader category="GTO & fold equity" suit="♣" functions={["bluffToValueRatio","valueToBluffRatio","bluffToValueRatioWithRake","valueToBluffRatioWithRake"]} />

## `bluffToValueRatio` \{#bluffToValueRatio\}

Bluffs per value bet on a polarized river bet: `bet / (pot + bet)`. 0 when `betSize` is 0.

```ts
bluffToValueRatio(potBeforeBet: number, betSize: number): number;
```

A bluff catcher calling `bet` to win `pot + bet` is indifferent when bluffs make up `bet / (pot + 2×bet)` of the bets, which is `bet / (pot + bet)` bluffs per value bet: `1/2` for a pot-sized bet. The ratio grows with bet size relative to pot, so larger bets can carry more bluffs per value hand.

Before 4.1.2 this returned the bluff **share** of all bets, `bet / (pot + 2×bet)` (`1/3` for a pot-sized bet). That quantity is the caller's breakeven equity, [`breakevenCallEquity(pot + bet, bet)`](/docs/reference/api/pot-odds-and-ev/pot-odds#breakevenCallEquity).

```js title="Example"
const poker = require('poker-calculations');

const pot = 100;
const bet = 75;

const b2v = poker.bluffToValueRatio(pot, bet);
console.log('bluffs per value bet', b2v);

const v2b = poker.valueToBluffRatio(pot, bet);
console.log('value bets per bluff', v2b);

// The bluff share of all bets is the caller's breakeven equity.
console.log('bluff share', poker.breakevenCallEquity(pot + bet, bet));
```

```text title="Output"
bluffs per value bet 0.42857142857142855
value bets per bluff 2.3333333333333335
bluff share 0.3
```

## `valueToBluffRatio` \{#valueToBluffRatio\}

Value bets per bluff, `(pot + bet) / bet` = `1 / bluffToValueRatio`; `Infinity` when `betSize` is 0.

```ts
valueToBluffRatio(potBeforeBet: number, betSize: number): number;
```

Express **how many value combos per bluff** the toy polarized model needs: `2` for a pot-sized bet. Returns `Infinity` when `betSize` is zero (degenerate sizing).

```js title="Example"
const poker = require('poker-calculations');

const pot = 50;
const bet = 50; // pot-sized bet

console.log(poker.valueToBluffRatio(pot, bet));
console.log(poker.bluffToValueRatio(pot, bet));

console.log(poker.valueToBluffRatio(pot, 0)); // Infinity
```

```text title="Output"
2
0.5
Infinity
```

## `bluffToValueRatioWithRake` \{#bluffToValueRatioWithRake\}

Bluffs per value bet when the caller wins the raked pot.

```ts
bluffToValueRatioWithRake(
  potBeforeBet: number,
  betSize: number,
  rakeFraction: number,
  rakeCap: number
): number;
```

`bet / (pot + bet − rake)`, with rake taken on the final pot `pot + 2×bet`. Rake shrinks what the caller wins, so the ratio is at least the no-rake [`bluffToValueRatio`](/docs/reference/api/gto-and-fold-equity/bluff-to-value#bluffToValueRatio). Returns `Infinity` when the rake leaves the caller nothing to gain (any number of bluffs is unprofitable to call). The bluff share of all bets is [`breakevenCallEquityWithRake(pot + bet, bet, rakeFraction, rakeCap)`](/docs/reference/api/pot-odds-and-ev/rake#breakevenCallEquityWithRake).

```js title="Example"
const poker = require('poker-calculations');

const pot = 100;
const bet = 50;
const rakeFraction = 0.05;
const rakeCap = 3;

const ratio = poker.bluffToValueRatioWithRake(pot, bet, rakeFraction, rakeCap);
console.log(ratio);
```

```text title="Output"
0.3401360544217687
```

## `valueToBluffRatioWithRake` \{#valueToBluffRatioWithRake\}

Value bets per bluff with rake.

```ts
valueToBluffRatioWithRake(
  potBeforeBet: number,
  betSize: number,
  rakeFraction: number,
  rakeCap: number
): number;
```

Reciprocal of [`bluffToValueRatioWithRake`](/docs/reference/api/gto-and-fold-equity/bluff-to-value#bluffToValueRatioWithRake); 0 when that ratio is `Infinity`.

```js title="Example"
const poker = require('poker-calculations');

const pot = 100;
const bet = 50;
const bluffVal = poker.bluffToValueRatioWithRake(pot, bet, 0.05, 3);
const valBluff = poker.valueToBluffRatioWithRake(pot, bet, 0.05, 3);
console.log(bluffVal * valBluff); // ≈ 1
```

```text title="Output"
1
```
