# `rangeCoverageFraction`
Return the share of the 1326 combo grid with positive mass.
<div className="apiSignature">{`rangeCoverageFraction(range: SparseRangeSpec | Float64Array): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `rangeCoverageFraction` when you need to return the share of the 1326 combo grid with positive mass.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.rangeCoverageFraction(range, 5);
console.log(result);
```
