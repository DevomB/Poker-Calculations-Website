# `rangeTopCombos`
List the highest-weight combos in a range.
<div className="apiSignature">{`rangeTopCombos(range: SparseRangeSpec | Float64Array, k: number): RangeComboWeight[]`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `rangeTopCombos` when you need to list the highest-weight combos in a range.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.rangeTopCombos(range, 5);
console.log(result);
```
