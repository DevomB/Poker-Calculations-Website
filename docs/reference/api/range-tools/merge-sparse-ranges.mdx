# `mergeSparseRanges`
Blend two ranges with caller-supplied weights and normalize the result.
<div className="apiSignature">{`mergeSparseRanges(a: SparseRangeSpec | Float64Array, b: SparseRangeSpec | Float64Array, weightA: number, weightB: number): Float64Array`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `mergeSparseRanges` when you need to blend two ranges with caller-supplied weights and normalize the result.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.mergeSparseRanges(range, 5);
console.log(result);
```
