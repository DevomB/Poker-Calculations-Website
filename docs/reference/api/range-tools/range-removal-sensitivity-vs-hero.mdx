# `rangeRemovalSensitivityVsHero`
Estimate hero-equity sensitivity to removing each live card from villain range.
<div className="apiSignature">{`rangeRemovalSensitivityVsHero(heroHoleCards: CardInput, boardCards: CardInput, range: SparseRangeSpec | Float64Array): Float64Array`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.
## Import
```js
const poker = require('poker-calculations');
```

```js
import { createRequire } from 'module';
```

## When to use
Use `rangeRemovalSensitivityVsHero` when building analysis, training, or simulator policy code that needs this calculation directly from the native package.
## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.rangeRemovalSensitivityVsHero(range, 5);
console.log(result);
```
