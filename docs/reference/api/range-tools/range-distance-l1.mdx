# `rangeDistanceL1`
Compute L1 distance between two normalized ranges.
<div className="apiSignature">{`rangeDistanceL1(a: SparseRangeSpec | Float64Array, b: SparseRangeSpec | Float64Array): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `rangeDistanceL1` when you need to compute L1 distance between two normalized ranges.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.rangeDistanceL1(range, 5);
console.log(result);
```
