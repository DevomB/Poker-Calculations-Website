# `normalizeSparseRange`
Normalize a dense or sparse 1326-combo range into a dense probability vector.
<div className="apiSignature">{`normalizeSparseRange(range: SparseRangeSpec | Float64Array): Float64Array`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `normalizeSparseRange` when you need to normalize a dense or sparse 1326-combo range into a dense probability vector.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.normalizeSparseRange(range, 5);
console.log(result);
```
