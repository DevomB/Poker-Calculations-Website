## `decideAction` \{#decideAction\}

Rule-based action from Monte Carlo equity, pot odds, and call EV; see [decideAction contract](/docs/reference/types/native-poker-state).

```ts
decideAction(
  state: NativePokerState | PokerStateBytes,
  config: NativeBotConfig,
  opponentModel?: NativeOpponentModel | null,
  heroSeat?: number
): DecisionResult;
```

Wire a rule-based villain or research bot in your own engine—automated opponents in simulators, not live assistance on third-party sites. Pass a complete `NativePokerState` snapshot each decision.

- Hero is the player in `heroSeat`, or the acting player when it is omitted. It throws when that seat is empty, hero has folded or is all-in, or the hand is over, and when `monteCarloSimulations` is below 1.
- Equity is estimated against random hands, not the actual opponents' cards. With nothing to call it is against `monteCarloVillains` random hands.
- A call is priced pot layer by pot layer. Hero's chips are added to the commitments and the pot is split into side-pot layers; hero can win only the layers it contributes to, and in each it faces random hands for the players still in that layer. The call is worth the expected winnings from those layers minus its cost (hero's stack when it is short). Earlier streets count as one layer unless every player's `totalCommittedHand` is set consistently. When every layer has `monteCarloVillains` opponents (heads-up, for example) this is the plain equity estimate applied to the pot.
- `raiseBy` is the chips added on top of the call, kept between the minimum raise and all-in.

```js title="Example"
const poker = require('poker-calculations');

const state = {
  players: [
    { holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0 },
    { holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false },
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actedThisStreet: [false, true],
};

const decision = poker.decideAction(
  state,
  { monteCarloSimulations: 2000, rngSeed: 1, aggressionThreshold: 0.55 },
  null,
  0,
);

console.log(decision.action, decision.raiseBy);
```

```text title="Output"
raise 17
```

Bots and simulators that call `decideAction` often and must keep the JS thread responsive. Optional [`AsyncOptions`](/docs/reference/types/async-options) cancel Monte Carlo inside `decideAction` via `AbortSignal`.

```js title="Example"
const poker = require('poker-calculations');
const state = {
  players: [
    { holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0 },
    { holeCards: ['7c', '7d'], stack: 180, seat: 1, committedThisStreet: 10 },
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};
const d = await poker.decideActionAsync(state, { monteCarloSimulations: 2000, rngSeed: 1 }, null, 0);
console.log(d.action, d.raiseBy);
```

```text title="Output"
raise 17
```

Use `decideActionWithDiagnostics` when you also want hero's legal actions next to the decision, to check or log it. The `ev` field is not filled in.

```js title="Example"
const poker = require('poker-calculations');
const state = {
  players: [
    {holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0},
    {holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false},
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};

const result = poker.decideActionWithDiagnostics(state, {monteCarloSimulations: 2000, rngSeed: 1}, null, 0);
console.log(result);
```

```text title="Output"
{
  decision: { action: 'raise', raiseBy: 17 },
  legalActions: {
    canFold: true,
    canCheck: false,
    canCall: true,
    canRaise: true,
    toCall: 10,
    minRaiseTo: 12,
    maxRaiseTo: 200,
    actingIndex: 0
  },
  reason: 'rule-based equity and pot-odds decision'
}
```
