## `decideAction` \{#decideAction\}
Rule-based action using MC equity (or strength fallback when sim count is 0), pot odds, call EV; see [decideAction contract](/docs/reference/types/native-poker-state).

```ts
decideAction(
  state: NativePokerState | PokerStateBytes,
  config: NativeBotConfig,
  opponentModel?: NativeOpponentModel | null,
  heroSeat?: number
): DecisionResult;
```

</details>

Wire a rule-based villain or research bot in your own engine—automated opponents in simulators, not live assistance on third-party sites. Pass a complete `NativePokerState` snapshot each decision.

```js title="Example"
const poker = require('poker-calculations');

const state = {
  players: [
    { holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0 },
    { holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false },
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actedThisStreet: [false, true],
};

const decision = poker.decideAction(
  state,
  { monteCarloSimulations: 2000, rngSeed: 1, aggressionThreshold: 0.55 },
  null,
  0,
);

console.log(decision.action, decision.raiseBy);
```

```text title="Output"
raise 17
```

Bots and simulators that call `decideAction` often and must keep the JS thread responsive. Optional [`AsyncOptions`](/docs/reference/types/async-options) cancel Monte Carlo inside `decideAction` via `AbortSignal`.

```js title="Example"
const poker = require('poker-calculations');
const state = {
  players: [
    { holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0 },
    { holeCards: ['7c', '7d'], stack: 180, seat: 1, committedThisStreet: 10 },
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};
const d = await poker.decideActionAsync(state, { monteCarloSimulations: 2000, rngSeed: 1 }, null, 0);
console.log(d.action, d.raiseBy);
```

```text title="Output"
raise 17
```

Use `decideActionWithDiagnostics` when you need to run native decision logic and include legal-action and EV diagnostics.

```js title="Example"
const poker = require('poker-calculations');
const state = {
  players: [
    {holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0},
    {holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false},
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};

const result = poker.decideActionWithDiagnostics(state, {monteCarloSimulations: 0});
console.log(result);
```

```text title="Output"
{
  decision: { action: 'fold', raiseBy: 0 },
  legalActions: {
    canFold: true,
    canCheck: false,
    canCall: true,
    canRaise: true,
    toCall: 10,
    minRaiseTo: 12,
    maxRaiseTo: 200,
    actingIndex: 0
  },
  reason: 'rule-based equity and pot-odds decision'
}
```
