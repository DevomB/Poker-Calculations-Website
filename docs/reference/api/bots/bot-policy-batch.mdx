# Batch bot policy

<ApiFamilyHeader category="Bots & game state" suit="♥" functions={["runBotPolicyBatch"]} />

## `runBotPolicyBatch` \{#runBotPolicyBatch\}
Run native policy diagnostics over many states.

```ts
runBotPolicyBatch(
  states: Array<NativePokerState | PokerStateBytes>,
  config: NativeBotConfig,
  opponentModels?: Array<NativeOpponentModel | null>
): DecisionDiagnosticResult[];
```

Use `runBotPolicyBatch` when you need to run native policy diagnostics over many states.

```js title="Example"
const poker = require('poker-calculations');
const state = {
  players: [
    { holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0 },
    { holeCards: ['7c', '7d'], stack: 180, seat: 1, committedThisStreet: 10 },
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};
const results = poker.runBotPolicyBatch([state, state], { monteCarloSimulations: 500, rngSeed: 1 });
console.log(results.map((r) => r.decision.action));
```

```text title="Output"
[ 'raise', 'raise' ]
```
