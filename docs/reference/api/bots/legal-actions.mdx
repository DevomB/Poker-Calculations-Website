# Legal actions

<ApiFamilyHeader category="Bots & game state" suit="♥" functions={["legalActionSummary","actionMaskFromState"]} />

## `legalActionSummary` \{#legalActionSummary\}
Return legal action flags and raise bounds for a poker state.

```ts
legalActionSummary(state: NativePokerState | PokerStateBytes): LegalActionSummaryResult;
```

<details>
<summary>Types: <code>LegalActionSummaryResult</code>, <code>NativePokerState</code></summary>

```ts
interface LegalActionSummaryResult {
  canFold: boolean;
  canCheck: boolean;
  canCall: boolean;
  canRaise: boolean;
  toCall: number;
  minRaiseTo: number;
  maxRaiseTo: number;
  actingIndex: number;
}

interface NativePokerState {
  players: Array<{
    name?: string;
    holeCards: CardInput;
    stack?: number;
    committedThisStreet?: number;
    totalCommittedHand?: number;
    folded?: boolean;
    seat?: number;
  }>;
  communityCards: CardInput;
  phase: string;
  pot?: number;
  currentBet?: number;
  buttonSeat?: number;
  smallBlind?: number;
  bigBlind?: number;
  actingIndex?: number;
  lastRaiseIncrement?: number;
  streetOpeningIndex?: number;
  actedThisStreet: boolean[];
}
```

Field notes: [`LegalActionSummaryResult`](/docs/reference/types/legal-action-summary-result) · [`NativePokerState`](/docs/reference/types/native-poker-state)

</details>

Use `legalActionSummary` when you need to return legal action flags and raise bounds for a poker state.

```js title="Example"
const poker = require('poker-calculations');
const state = {
  players: [
    {holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0},
    {holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false},
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};

const result = poker.legalActionSummary(state, {monteCarloSimulations: 0});
console.log(result);
```

```text title="Output"
{
  canFold: true,
  canCheck: false,
  canCall: true,
  canRaise: true,
  toCall: 10,
  minRaiseTo: 12,
  maxRaiseTo: 200,
  actingIndex: 0
}
```
