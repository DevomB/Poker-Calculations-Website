# Threaded simulation

<ApiFamilyHeader category="Monte Carlo equity" suit="♥" functions={["parallelHandSimulation","parallelHandSimulationAsync"]} />

## `parallelHandSimulation` \{#parallelHandSimulation\}
Same with worker threads and distinct seeds per chunk.

```ts
parallelHandSimulation(
  holeCards: CardInput,
  board: CardInput,
  numSimulations: number,
  baseSeed: number,
  villains: number,
  numThreads: number
): number;
```

Use on multi-core servers when `simulateHandOutcome` is CPU-bound and you want the same MC model with higher throughput. Each thread advances `baseSeed` so chunks stay independent.

```js title="Example"
const poker = require('poker-calculations');

const equity = poker.parallelHandSimulation(
  ['As', 'Ks'],
  [],
  200_000,
  9001,
  1,
  4,
);
console.log(equity.toFixed(4));
```

```text title="Output"
0.6682
```

Board length may be 0–5; known cards must not overlap between hero and board.

## `parallelHandSimulationAsync` \{#parallelHandSimulationAsync\}
Same as `parallelHandSimulation`; runs on the libuv thread pool (non-blocking).

```ts
parallelHandSimulationAsync(
  holeCards: CardInput,
  board: CardInput,
  numSimulations: number,
  baseSeed: number,
  villains: number,
  numThreads: number,
  options?: AsyncOptions
): Promise<number>;
```

Non-blocking version of [`parallelHandSimulation`](/docs/reference/api/monte-carlo/parallel-hand-simulation#parallelHandSimulation). Optional [`AsyncOptions`](/docs/reference/types/async-options) cancel long runs via `AbortSignal`.

```js title="Example"
const poker = require('poker-calculations');
const hole = ['Ah', 'Kh'];
const board = ['Qh', 'Jh', '2c'];
const eq = await poker.parallelHandSimulationAsync(hole, board, 20_000, 99, 1, 4);
console.log(eq.toFixed(3));

// Cancel a long run with an AbortSignal
const ac = new AbortController();
const pending = poker.parallelHandSimulationAsync(hole, board, 5_000_000, 99, 1, 4, { signal: ac.signal });
ac.abort();
await pending.catch((e) => console.log(e.name)); // AbortError
```

```text title="Output"
0.760
AbortError
```
