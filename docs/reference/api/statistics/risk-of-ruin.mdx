# Risk of ruin

<ApiFamilyHeader category="Statistics & bankroll" suit="♣" functions={["riskOfRuinDiffusionApprox","bankrollForTargetRorDiffusion","varianceToStandardDeviationPerHand"]} />

## `riskOfRuinDiffusionApprox` \{#riskOfRuinDiffusionApprox\}
diffusion-style risk of ruin in (0,1].

```ts
riskOfRuinDiffusionApprox(driftPerHand: number, variancePerHand: number, bankroll: number): number;
```

Rough **bankroll survival** modeling from per-hand drift (expected chip change) and variance, treated as a diffusion approximation. Study tool only—not a substitute for full bankroll simulation. Pair with `bankrollForTargetRorDiffusion` to size bankroll for a target ruin probability.

```js title="Example"
const poker = require('poker-calculations');

const driftPerHand = 0.8; // bb/hand EV
const variancePerHand = 120; // bb²/hand
const bankrollBb = 200;

const ror = poker.riskOfRuinDiffusionApprox(driftPerHand, variancePerHand, bankrollBb);
console.log('approx risk of ruin:', (ror * 100).toFixed(2) + '%');

const bankrollNeeded = poker.bankrollForTargetRorDiffusion(
  driftPerHand,
  variancePerHand,
  0.01,
);
console.log('bb for 1% ROR:', bankrollNeeded);
```

```text title="Output"
approx risk of ruin: 6.95%
bb for 1% ROR: 345.38776394910684
```

**Returns** `number` — approximate probability of ruin in `(0, 1]` when driftPerHand > 0; returns `1` when driftPerHand ≤ 0 (non-positive edge).

## `bankrollForTargetRorDiffusion` \{#bankrollForTargetRorDiffusion\}
inverse of `riskOfRuinDiffusionApprox` for bankroll.

```ts
bankrollForTargetRorDiffusion(
  driftPerHand: number,
  variancePerHand: number,
  targetRor: number
): number;
```

Inverse of `riskOfRuinDiffusionApprox`: given per-hand **drift and variance**, find how large a bankroll must be for a chosen ruin probability (e.g. 1% or 5%). Useful for spreadsheets and study charts, not live bankroll advice.

```js title="Example"
const poker = require('poker-calculations');

const driftPerHand = 1.2;
const variancePerHand = 150;
const targetRor = 0.05;

const bankroll = poker.bankrollForTargetRorDiffusion(
  driftPerHand,
  variancePerHand,
  targetRor,
);

const check = poker.riskOfRuinDiffusionApprox(
  driftPerHand,
  variancePerHand,
  bankroll,
);
console.log({ bankroll, checkRor: check });
```

```text title="Output"
{ bankroll: 187.23326709712444, checkRor: 0.05000000000000001 }
```

**Returns** `number` — bankroll size B such that `riskOfRuinDiffusionApprox(driftPerHand, variancePerHand, B)` ≈ targetRor (same diffusion model as [`riskOfRuinDiffusionApprox`](/docs/reference/api/statistics/risk-of-ruin#riskOfRuinDiffusionApprox)).

## `varianceToStandardDeviationPerHand` \{#varianceToStandardDeviationPerHand\}
`sqrt(variance)` per hand.

```ts
varianceToStandardDeviationPerHand(variancePerHand: number): number;
```

Convert per-hand variance to standard deviation (`sqrt`).

```js title="Example"
const poker = require('poker-calculations');

console.log(poker.varianceToStandardDeviationPerHand(4)); // 2
```

```text title="Output"
2
```
