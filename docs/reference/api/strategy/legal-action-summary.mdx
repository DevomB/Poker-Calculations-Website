# `legalActionSummary`
Return legal action flags and raise bounds for a poker state.
<div className="apiSignature">{`legalActionSummary(state: NativePokerState | PokerStateBytes): LegalActionSummaryResult`}</div>

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `legalActionSummary` when you need to return legal action flags and raise bounds for a poker state.

## How to use
```js
const poker = require('poker-calculations');
const state = {
  players: [
    {holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0},
    {holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false},
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};

const result = poker.legalActionSummary(state, {monteCarloSimulations: 0});
console.log(result);
```
