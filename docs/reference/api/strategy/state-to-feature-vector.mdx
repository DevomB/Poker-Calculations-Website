# `stateToFeatureVector`
Convert a poker state into a compact numeric feature vector.
<div className="apiSignature">{`stateToFeatureVector(state: NativePokerState | PokerStateBytes): Float64Array`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.
## Import
```js
const poker = require('poker-calculations');
```
## ESM (Node)
```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```
## When to use
Use `stateToFeatureVector` when building analysis, training, or simulator policy code that needs this calculation directly from the native package.
## How to use
```js
const poker = require('poker-calculations');
const state = {
  players: [
    {holeCards: ['Ah', 'Kh'], stack: 200, seat: 0, committedThisStreet: 0},
    {holeCards: ['7c', '7d'], stack: 180, seat: 1, folded: false},
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  actingIndex: 0,
  actedThisStreet: [false, true],
};

const result = poker.stateToFeatureVector(state, {monteCarloSimulations: 0});
console.log(result);
```
