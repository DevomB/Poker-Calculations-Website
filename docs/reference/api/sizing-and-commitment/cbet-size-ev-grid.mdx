# `cbetSizeEvGrid`
Evaluate continuation-bet candidates across a sizing grid.
<div className="apiSignature">{`cbetSizeEvGrid(heroRange: SparseRangeSpec | Float64Array, villainRange: SparseRangeSpec | Float64Array, board: CardInput, pot: number, betSizes: F64VectorInput): EvGridResult`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `cbetSizeEvGrid` when you need to evaluate continuation-bet candidates across a sizing grid.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.cbetSizeEvGrid(range, range, ['Qh', 'Jh', '2c'], 100, [33, 66, 100]);
console.log(result);
```
