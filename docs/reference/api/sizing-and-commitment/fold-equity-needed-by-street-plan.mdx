# `foldEquityNeededByStreetPlan`
Estimate fold equity needed for a planned multi-street betting line.
<div className="apiSignature">{`foldEquityNeededByStreetPlan(pot: number, bets: F64VectorInput, equityWhenCalled: number): number`}</div>

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `foldEquityNeededByStreetPlan` when you need to estimate fold equity needed for a planned multi-street betting line.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.foldEquityNeededByStreetPlan(range, range, ['Qh', 'Jh', '2c'], 100, [33, 66, 100]);
console.log(result);
```
