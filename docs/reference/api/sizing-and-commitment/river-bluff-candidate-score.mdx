# `riverBluffCandidateScore`
Score a hand as a river bluff candidate from blocker and board interaction.
<div className="apiSignature">{`riverBluffCandidateScore(heroHoleCards: CardInput, boardCards: CardInput, villainRange: SparseRangeSpec | Float64Array): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `riverBluffCandidateScore` when you need to score a hand as a river bluff candidate from blocker and board interaction.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.riverBluffCandidateScore(range, range, ['Qh', 'Jh', '2c'], 100, [33, 66, 100]);
console.log(result);
```
