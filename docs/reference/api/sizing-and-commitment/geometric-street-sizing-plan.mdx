# `geometricStreetSizingPlan`
Generate geometric bet sizes for committing a stack over remaining streets.
<div className="apiSignature">{`geometricStreetSizingPlan(pot: number, effectiveStack: number, streetsRemaining: number): Float64Array`}</div>

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `geometricStreetSizingPlan` when you need to generate geometric bet sizes for committing a stack over remaining streets.

## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.geometricStreetSizingPlan(range, range, ['Qh', 'Jh', '2c'], 100, [33, 66, 100]);
console.log(result);
```
