# `betSizingIndifferencePoint`
Solve a simple bet-size indifference point from fold frequency and called equity.
<div className="apiSignature">{`betSizingIndifferencePoint(pot: number, foldFrequency: number, equityWhenCalled: number): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.
## Import
```js
const poker = require('poker-calculations');
```
## ESM (Node)
```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```
## When to use
Use `betSizingIndifferencePoint` when building analysis, training, or simulator policy code that needs this calculation directly from the native package.
## How to use
```js
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.betSizingIndifferencePoint(range, range, ['Qh', 'Jh', '2c'], 100, [33, 66, 100]);
console.log(result);
```
