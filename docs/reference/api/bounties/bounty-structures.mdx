# Bounty structures

<ApiFamilyHeader category="Bounties" suit="♦" functions={["progressiveKoPostedBounty","mysteryBountyExpectedValue","pkoWinnerTakeRemainingBounties"]} />

## `progressiveKoPostedBounty` \{#progressiveKoPostedBounty\}

Progressive KO posted bounty: `base + carryFraction * collected`. `knockouts` length n = dollars already collected onto each head; n×n (nested or flat) = M[i][j] weight that i collected j's *base* bounty. `carryFraction` 1.0 = classic PKO.

```ts
progressiveKoPostedBounty(
  baseBounties: F64VectorInput,
  knockouts: F64VectorInput | number[][],
  carryFraction: number,
  returnFormat?: F64ReturnFormat
): number[] | Float64Array;
```

```js title="Example"
const poker = require('poker-calculations');
// Base bounties $50; seat 0 has already collected $50 onto its head
const posted = poker.progressiveKoPostedBounty([50, 50, 50], [50, 0, 0], 0.5);
console.log(posted);
```

```text title="Output"
[ 75, 50, 50 ]
```

## `mysteryBountyExpectedValue` \{#mysteryBountyExpectedValue\}

Remaining mystery prizes: weighted mean of one knockout, leftover-pool sum, and optional expected total of `k` draws without replacement (`k` omitted or 0 skips it). `weights` are relative draw chances of each bounty (equal if omitted); unequal weights with `0 < k < n` use the Harville top-k inclusion probabilities, bounded like ICM (fields over 20 need few draws).

```ts
mysteryBountyExpectedValue(
  values: F64VectorInput,
  weights?: F64VectorInput | number,
  k?: number
): MysteryBountyEvResult;
```

<details>
<summary>Types: <code>MysteryBountyEvResult</code></summary>

```ts
interface MysteryBountyEvResult {
  oneDraw: number;
  allRemaining: number;
  sampleK: number;
  k: number;
}
```


</details>

```js title="Example"
const poker = require('poker-calculations');
const prizes = [1000, 250, 100, 50, 50, 25, 25, 25];
console.log(poker.mysteryBountyExpectedValue(prizes));
```

```text title="Output"
{ oneDraw: 190.625, allRemaining: 1525, sampleK: 0, k: 0 }
```

Each entry of `values` is one bounty envelope, and each draw takes one of the remaining envelopes with probability proportional to its weight, without replacement. So `oneDraw = Σ wᵢ valueᵢ / Σ wᵢ`, and `sampleK = Σ valueᵢ × P(i is among the k draws)`. With equal weights that is `k × mean` (pass `k` as the second argument to keep equal weights); with unequal weights it uses exact inclusion probabilities. `sampleK` never exceeds `allRemaining`, rises with `k`, and equals it at `k = n`. Before 4.2.0 unequal weights were treated as if draws were with replacement: `([100, 1, 1], [1000, 1, 1], 2)` returned 199.6 from a 102 pool.

```js title="Example"
const poker = require('poker-calculations');
// A 100 bounty that is 1000 times as likely to be drawn as each of two 1-chip bounties.
// Two draws almost surely include the 100 plus one of the 1s (about 101); three draws take the whole 102.
for (const k of [1, 2, 3]) {
  console.log(k, poker.mysteryBountyExpectedValue([100, 1, 1], [1000, 1, 1], k).sampleK);
}
```

```text title="Output"
1 99.80239520958082
2 100.99980259261694
3 102
```

## `pkoWinnerTakeRemainingBounties` \{#pkoWinnerTakeRemainingBounties\}

Add leftover bounty pool to first prize. Returns adjusted payouts, ICM $EV on those payouts, Harville win probs, and P(i first) * remaining pool.

```ts
pkoWinnerTakeRemainingBounties(
  stacks: F64VectorInput,
  payouts: F64VectorInput,
  remainingBountyPool: number,
  returnFormat?: F64ReturnFormat
): PkoWinnerTakeBountiesResult;
```

<details>
<summary>Types: <code>PkoWinnerTakeBountiesResult</code></summary>

```ts
interface PkoWinnerTakeBountiesResult {
  adjustedPayouts: number[] | Float64Array;
  ev: number[] | Float64Array;
  winProbabilities: number[] | Float64Array;
  bountyToWinnerEv: number[] | Float64Array;
}

/** Equity if called: scalar P(win) with P(tie)=0, `[equity, tie]`, or `[win, tie, lose]`. */
```


</details>

```js title="Example"
const poker = require('poker-calculations');
const r = poker.pkoWinnerTakeRemainingBounties([5000, 3000, 2000], [500, 300, 200], 120);
console.log(r);
```

```text title="Output"
{
  adjustedPayouts: [ 620, 300, 200 ],
  ev: [ 443.92857142857144, 363.5, 312.57142857142856 ],
  winProbabilities: [ 0.5, 0.3, 0.2 ],
  bountyToWinnerEv: [ 60, 36, 24 ]
}
```
