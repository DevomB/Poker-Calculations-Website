# 2-7 equity

<ApiFamilyHeader category="Stud, razz & 2-7" suit="♦" functions={["deuceSevenDrawEquityVsKnown","deuceSevenMultiwayShowdown"]} />

## `deuceSevenDrawEquityVsKnown` \{#deuceSevenDrawEquityVsKnown\}
Hero equity after both stand or draw (ties 0.5). Omit options to stand pat. Exact replacement tree when small; otherwise Monte Carlo.

```ts
deuceSevenDrawEquityVsKnown(
  hero: CardInput,
  villain: CardInput,
  options?: DeuceSevenDrawOptions
): number;
```

<details>
<summary>Types: <code>DeuceSevenDrawOptions</code></summary>

```ts
interface DeuceSevenDrawOptions {
  /** Cards to throw, or a count (best discard of that size). */
  heroDiscard?: number | CardInput;
  villainDiscard?: number | CardInput;
  heroKeep?: CardInput;
  villainKeep?: CardInput;
  extraDead?: CardInput;
  /** Used only when the replacement tree is too large for exact enumeration. Default 400. */
  trials?: number;
  seed?: number;
}
```


</details>

Equity after the single draw, given what each player throws. Omit options to stand pat.

```js title="Example"
const poker = require('poker-calculations');
// Hero draws one to 7-5-3-2; villain stands pat with an 8-6
const eq = poker.deuceSevenDrawEquityVsKnown(
  ['7h', '5d', '3c', '2s', 'Kh'],
  ['8c', '6d', '4s', '3d', '2c'],
  { heroDiscard: ['Kh'], villainDiscard: 0 },
);
console.log(eq.toFixed(3));
```

```text title="Output"
0.143
```

## `deuceSevenMultiwayShowdown` \{#deuceSevenMultiwayShowdown\}
Pot-share vector for 2–8 disjoint 5-card hands. Ties split.

```ts
deuceSevenMultiwayShowdown(hands: CardInput[]): number[];
```

```js title="Example"
const poker = require('poker-calculations');
console.log(poker.deuceSevenMultiwayShowdown([
  ['7h', '5d', '4c', '3s', '2h'],
  ['8c', '6d', '4s', '3d', '2c'],
  ['9h', '8d', '6c', '5s', '3h'],
]));
```

```text title="Output"
[ 1, 0, 0 ]
```
