# Overlapping outs

## `flopToRiverAtLeastOneHitUnionTwoCategories` \{#flopToRiverAtLeastOneHitUnionTwoCategories\}

two out categories with card-level overlap; `sharedAb` = intersection size. Uses union cardinality `outsA + outsB - sharedAb` in the two-draw formula.

```ts
flopToRiverAtLeastOneHitUnionTwoCategories(
  unseenAfterFlop: number,
  outsA: number,
  outsB: number,
  sharedAb: number
): number;
```

Combine **flush outs and straight outs** when some cards count toward both (overlap). Union size is `outsA + outsB - sharedAb` before the two-street hit formula runs.

```js title="Example"
const poker = require('poker-calculations');

const unseen = 47;
const flushOuts = 9;
const straightOuts = 4;
const shared = 1; // one card is both flush and straight out

const p = poker.flopToRiverAtLeastOneHitUnionTwoCategories(
  unseen,
  flushOuts,
  straightOuts,
  shared
);
console.log(p);
```

```text title="Output"
0.44958371877890846
```

## `flopToRiverAtLeastOneHitUnionThreeCategories` \{#flopToRiverAtLeastOneHitUnionThreeCategories\}

three categories; union = `oa+ob+oc - sab - sac - sbc + sabc`.

```ts
flopToRiverAtLeastOneHitUnionThreeCategories(
  unseenAfterFlop: number,
  outsA: number,
  outsB: number,
  outsC: number,
  sharedAb: number,
  sharedAc: number,
  sharedBc: number,
  sharedAbc: number
): number;
```

Three-way out overlap (e.g. flush + straight + pair outs) needs **inclusion–exclusion on card counts** before applying the flop→river formula. Pass pairwise and triple intersection sizes as actual cards, not combo counts.

```js title="Example"
const poker = require('poker-calculations');

const p = poker.flopToRiverAtLeastOneHitUnionThreeCategories(
  47, // unseen after flop
  9, 4, 3, // outs A, B, C
  1, 0, 0, // shared AB, AC, BC
  0         // shared ABC
);
console.log(p);
```

```text title="Output"
0.5411655874190564
```

## `flopToRiverAtLeastOneHitUnionFourCategories` \{#flopToRiverAtLeastOneHitUnionFourCategories\}

four out categories; inclusion–exclusion on **card counts** (pair/triple/four-way intersection sizes). Pair order (0,1)(0,2)(0,3)(1,2)(1,3)(2,3); triples (0,1,2)(0,1,3)(0,2,3)(1,2,3); last arg four-way.

```ts
flopToRiverAtLeastOneHitUnionFourCategories(
  unseenAfterFlop: number,
  outsA: number,
  outsB: number,
  outsC: number,
  outsD: number,
  s01: number,
  s02: number,
  s03: number,
  s12: number,
  s13: number,
  s23: number,
  s012: number,
  s013: number,
  s023: number,
  s123: number,
  fourWay: number
): number;
```

Maximum structured overlap case: four out families with all pairwise, triple, and four-way **shared card counts**. Pair indices follow `(0,1)(0,2)(0,3)(1,2)(1,3)(2,3)` as documented in `index.d.ts`.

```js title="Example"
const poker = require('poker-calculations');

// Toy: four small categories, mostly disjoint
const p = poker.flopToRiverAtLeastOneHitUnionFourCategories(
  47,
  4, 4, 3, 2,       // outs A–D
  0, 0, 0, 0, 0, 0, // pairwise shared
  0, 0, 0, 0,       // triple shared
  0                 // four-way shared
);
console.log(p);
```

```text title="Output"
0.4810360777058279
```

## `flopToTurnAtLeastOneHitUnionTwoCategories` \{#flopToTurnAtLeastOneHitUnionTwoCategories\}

Two overlapping categories, one street (flop→turn).

```ts
flopToTurnAtLeastOneHitUnionTwoCategories(
  unseen: number,
  outsA: number,
  outsB: number,
  sharedAb: number
): number;
```

Flop→turn hit rate when two out categories overlap (e.g. flush + straight). Union size is `outsA + outsB - sharedAb` before the one-street formula.

```js title="Example"
const poker = require('poker-calculations');

const unseen = 47;
const flushOuts = 9;
const straightOuts = 4;
const shared = 1; // one card counts toward both

const p = poker.flopToTurnAtLeastOneHitUnionTwoCategories(
  unseen,
  flushOuts,
  straightOuts,
  shared,
);
console.log(p); // 12/47 — same union logic as flop→river, one card only
```

```text title="Output"
0.2553191489361702
```

## `turnToRiverAtLeastOneHitUnionTwoCategories` \{#turnToRiverAtLeastOneHitUnionTwoCategories\}

Two overlapping categories, turn→river.

```ts
turnToRiverAtLeastOneHitUnionTwoCategories(
  unseen: number,
  outsA: number,
  outsB: number,
  sharedAb: number

```

Turn→river with two overlapping out categories. Mirror of [`flopToTurnAtLeastOneHitUnionTwoCategories`](/docs/reference/api/draws-and-outs/overlapping-outs#flopToTurnAtLeastOneHitUnionTwoCategories) on the river street.

```js title="Example"
const p = poker.turnToRiverAtLeastOneHitUnionTwoCategories(unseen, 9, 4, 1);

```
