# Rule of 2 and 4

<ApiFamilyHeader category="Draws & outs" suit="♥" functions={["ruleOfTwoEquity","ruleOfFourEquity","estimatedOutsFromRuleOfTwo","estimatedOutsFromRuleOfFour"]} />

## `ruleOfTwoEquity` \{#ruleOfTwoEquity\}

Out-count × 2% cap heuristic (one card).

```ts
ruleOfTwoEquity(outs: number): number;
```

Facing **one card to come** (turn only, or river only), multiply outs by 2% for a fast equity estimate. Pair with `hypergeometricOneCardHitProbability` when you want the exact one-card rate.

```js title="Example"
const poker = require('poker-calculations');

const outs = 8;
console.log(poker.ruleOfTwoEquity(outs)); // ~0.16

console.log(poker.hypergeometricOneCardHitProbability(outs, 46));
```

```text title="Output"
0.16
0.17391304347826086
```

## `ruleOfFourEquity` \{#ruleOfFourEquity\}

Out-count × 4% cap heuristic (turn+river).

```ts
ruleOfFourEquity(outs: number): number;
```

On the flop, estimate **two-card equity** quickly: multiply clean outs by 4% (capped by the native implementation). Good for live/table mental math before you run exact `flopToRiverAtLeastOneHitProbability`.

```js title="Example"
const poker = require('poker-calculations');

const outs = 9; // flush draw
console.log(poker.ruleOfFourEquity(outs)); // ~0.36 (36%)

console.log(
  poker.flopToRiverAtLeastOneHitProbability(outs, 47)
); // exact two-street from 47 unseen
```

```text title="Output"
0.36
0.3496762257169288
```

## `estimatedOutsFromRuleOfTwo` \{#estimatedOutsFromRuleOfTwo\}

Outs implied by the rule of two (2% per out): `equity × 50`, the uncapped inverse of `ruleOfTwoEquity` (0.18 → 9 outs), at most `unseenCards`. `equity` must be in [0, 1].

```ts
estimatedOutsFromRuleOfTwo(equity: number, unseenCards: number): number;
```

Back-solve the out count behind a one-street equity estimate. It inverts [`ruleOfTwoEquity`](/docs/reference/api/draws-and-outs/rule-of-two-and-four#ruleOfTwoEquity) exactly below that rule's cap: 9 outs × 2% is 0.18, and 0.18 gives back 9. The forward rule saturates (48 outs, equity 1), so equities near 1 have no unique inverse; the result never exceeds `unseenCards`. Before 4.2.0 this multiplied by `unseenCards / 2` instead of 50 and returned 4.23 for 0.18.

```js title="Example"
const poker = require('poker-calculations');

const equity = poker.ruleOfTwoEquity(9); // 0.18
console.log(poker.estimatedOutsFromRuleOfTwo(equity, 47)); // 9
console.log(poker.estimatedOutsFromRuleOfTwo(1, 47)); // capped at the 47 unseen cards
```

```text title="Output"
9
47
```

## `estimatedOutsFromRuleOfFour` \{#estimatedOutsFromRuleOfFour\}

Rule of four (4% per out, two cards to come): `equity × 25` (0.36 → 9 outs), at most `unseenCards`.

```ts
estimatedOutsFromRuleOfFour(equity: number, unseenCards: number): number;
```

Convert **flop→river equity** into an implied out count for teaching or UI sliders. It inverts [`ruleOfFourEquity`](/docs/reference/api/draws-and-outs/rule-of-two-and-four#ruleOfFourEquity) below its cap: a 9-out flush draw is 36% by the rule, and 0.36 gives back 9. The exact two-card hit rate for those 9 outs is a little lower, which is why the rule of four is a heuristic.

```js title="Example"
const poker = require('poker-calculations');

const unseenAfterFlop = 47;
console.log(poker.estimatedOutsFromRuleOfFour(0.36, unseenAfterFlop)); // 9

console.log(poker.flopToRiverAtLeastOneHitProbability(9, unseenAfterFlop)); // exact: ~0.35
```

```text title="Output"
9
0.3496762257169288
```
