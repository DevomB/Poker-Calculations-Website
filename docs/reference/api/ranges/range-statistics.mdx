## `rangeComboCount` \{#rangeComboCount\}

Count active combos in a dense or sparse range.

```ts
rangeComboCount(range: SparseRangeSpec | Float64Array, minWeight?: number): number;
```

Use `rangeComboCount` when you need to count active combos in a dense or sparse range.

```js title="Example"
const poker = require('poker-calculations');
const range = new Float64Array(1326);
range.fill(1 / 1326);

const result = poker.rangeComboCount(range, 5);
console.log(result);
```

```text title="Output"
0
```

## `villainPolarizedRangeScore` \{#villainPolarizedRangeScore\}

The Gini coefficient of the range weights (the same value as `rangeGiniCoefficient`), clamped to `[0, 1]`. Higher means the weight sits on fewer combos. The `board` argument is accepted but not used.

```ts
villainPolarizedRangeScore(range: SparseRangeSpec | Float64Array, board: CardInput): number;
```

Use `villainPolarizedRangeScore` when you need to score how polarized a villain range is.

```js title="Example"
const poker = require('poker-calculations');
const range = poker.rangeFromNotationWeights([{ notation: 'AA', weight: 1 }, { notation: '76s', weight: 0.25 }]);
const board = ['Kh', '9d', '4c', '2s', 'Jh'];
// The Gini coefficient of the range weights, clamped to [0, 1]; the board is not used
console.log(poker.villainPolarizedRangeScore(range, board) === Math.min(1, Math.max(0, poker.rangeGiniCoefficient(range)))); // true
```

```text title="Output"
true
```
