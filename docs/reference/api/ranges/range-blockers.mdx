# Blockers and removal

## `materializeVillainRangeAfterBlockers` \{#materializeVillainRangeAfterBlockers\}

Dense **1326** combo weights after removing hero, board, and optional dead cards — plus combo count, weight sum, and Shannon entropy.

```ts
materializeVillainRangeAfterBlockers(
  range: Float64Array | SparseRangeSpec,
  heroHoleCards: CardInput,
  boardCards: CardInput,
  knownDead?: CardInput
): MaterializedVillainRangeResult;
```

<details>
<summary>Types: <code>MaterializedVillainRangeResult</code></summary>

```ts
interface MaterializedVillainRangeResult {
  weights1326: Float64Array;
  liveComboCount: number;
  weightSum: number;
  shannonEntropy: number;
}
```

Field notes: [`MaterializedVillainRangeResult`](/docs/reference/types/materialized-villain-range-result)

</details>

```js title="Example"
const poker = require('poker-calculations');

const range = new Float64Array(1326);
range.fill(1 / 1326);

const { weights1326, liveComboCount, weightSum, shannonEntropy } =
  poker.materializeVillainRangeAfterBlockers(
    range,
    ['Ah', 'Kh'],
    ['Qh', 'Jh', '2c'],
  );

console.log({ liveComboCount, weightSum, shannonEntropy });
console.log('First live weight:', weights1326.find((w) => w > 0));
```

```text title="Output"
{
  liveComboCount: 1081,
  weightSum: 0.8152337858220184,
  shannonEntropy: 6.985641817639109
}
First live weight: 0.0007541478129713424
```

## `rangeBlockerPressureByCard` \{#rangeBlockerPressureByCard\}

Per card (52 entries, deck order): the total range weight of the combos holding that card, after removing combos that use a `deadCards` card. Raw weighted counts in the range's units, not shares.

```ts
rangeBlockerPressureByCard(range: SparseRangeSpec | Float64Array, deadCards?: CardInput): Float64Array;
```

Use `rangeBlockerPressureByCard` when you need to measure how much range mass each deck card blocks. This is exact counting: entry `c` is the sum of the weights of live combos that contain card `c`. `deadCards` is a card list (`string[]` or `Uint8Array` of deck indices), not a number. Before 4.2.0 it was ignored, so dead cards still counted.

```js title="Example"
const poker = require('poker-calculations');
const range = new Float64Array(1326).fill(1); // every combo, weight 1

const pressure = poker.rangeBlockerPressureByCard(range, ['Ah', 'Kd']);
// Each card is in 51 combos. For a live card, 2 of them hold a dead card: 49 remain.
// A dead card is in no live combo: 0.
console.log(pressure.length, Math.min(...pressure), Math.max(...pressure), pressure.filter((x) => x === 0).length);
```

```text title="Output"
52 0 49 2
```

## `blockerMatrixByCard` \{#blockerMatrixByCard\}

Alias of `rangeBlockerPressureByCard` with `board` as the dead cards; a 52-element vector, not a matrix. For each deck id `0..51` it is the total weight of the live combos that contain that card (raw weighted counts, not shares).

```ts
blockerMatrixByCard(range: SparseRangeSpec | Float64Array, board?: CardInput): Float64Array;
```

Use `blockerMatrixByCard` when you need to return per-card blocker pressure for board and range analysis. Combos that use a board card are removed first, so the board's own cards are 0.

```js title="Example"
const poker = require('poker-calculations');
const range = poker.rangeFromNotationWeights([{ notation: 'AKs', weight: 1 }, { notation: 'QQ', weight: 1 }]);
const a = poker.blockerMatrixByCard(range, ['Qh', 'Jh', '2c']);
const b = poker.rangeBlockerPressureByCard(range, ['Qh', 'Jh', '2c']);
console.log(a.every((x, i) => x === b[i])); // identical results
```

```text title="Output"
true
```

## `rangeRemovalSensitivityVsHero` \{#rangeRemovalSensitivityVsHero\}

Per card, the change in hero's exact equity when villain's combos holding that card are removed.

```ts
rangeRemovalSensitivityVsHero(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range: SparseRangeSpec | Float64Array
): Float64Array;
```

Entry `c` is hero's equity when villain is known not to hold card `c` (its combos with `c` removed; `c` can still come on the board) minus hero's equity against the full range. Hero's and the board's cards are `0`. When every live combo holds `c`, villain cannot lack it, so the entry is `NaN` rather than an invented equity. Invalid cards, or a range with no live combo, throw. For a card that is dead (out of the runout too), see [`exactEquityCardRemovalGradient`](/docs/reference/api/runout-analysis/card-removal#exactEquityCardRemovalGradient).

```js title="Example"
const poker = require('poker-calculations');
const range = poker.rangeFromNotationWeights([{ notation: 'AKs', weight: 1 }, { notation: 'QQ', weight: 1 }, { notation: 'JTs', weight: 1 }]);
const s = poker.rangeRemovalSensitivityVsHero(['Ah', 'Qd'], ['Qh', 'Jc', '2s'], range);
console.log(s.length);
```

```text title="Output"
52
```
