# Range distance

<ApiFamilyHeader category="Ranges" suit="♦" functions={["rangeDistanceJensenShannon","rangeDistanceL1","rangeDistanceL2","rangeCosineSimilarity"]} />

## `rangeDistanceJensenShannon` \{#rangeDistanceJensenShannon\}

Compute Jensen-Shannon distance between two normalized ranges.

```ts
rangeDistanceJensenShannon(a: SparseRangeSpec | Float64Array, b: SparseRangeSpec | Float64Array): number;
```

Use `rangeDistanceJensenShannon` when you need to compute Jensen-Shannon distance between two normalized ranges.

```js title="Example"
const poker = require('poker-calculations');
const a = poker.rangeFromNotationWeights([{ notation: 'AA', weight: 1 }, { notation: 'KK', weight: 1 }]);
const b = poker.rangeFromNotationWeights([{ notation: 'KK', weight: 1 }, { notation: 'QQ', weight: 1 }]);
console.log(poker.rangeDistanceJensenShannon(a, a).toFixed(3), poker.rangeDistanceJensenShannon(a, b).toFixed(3));
```

```text title="Output"
0.000 0.589
```
