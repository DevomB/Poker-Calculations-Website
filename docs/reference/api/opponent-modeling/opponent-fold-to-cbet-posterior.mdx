# `opponentFoldToCbetPosterior`
Update a beta-binomial estimate for fold-to-c-bet frequency.
<div className="apiSignature">{`opponentFoldToCbetPosterior(priorAlpha: number, priorBeta: number, folds: number, continues: number): BetaBinomialFoldPosterior`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

```js
const poker = require('poker-calculations');
```

Use `opponentFoldToCbetPosterior` when building analysis, training, or simulator policy code that needs this calculation directly from the native package.

```js

const result = poker.opponentFoldToCbetPosterior(1, 1, 7, 5);
```
