# `opponentAggressionFactor`
Compute opponent aggression factor from bets, raises, and calls.
<div className="apiSignature">{`opponentAggressionFactor(bets: number, raises: number, calls: number): number`}</div>

## Import
```js
const poker = require('poker-calculations');
```

ESM (Node):

```js
import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const poker = require('poker-calculations');
```

## When to use
Use `opponentAggressionFactor` when you need to compute opponent aggression factor from bets, raises, and calls.

## How to use
```js
const poker = require('poker-calculations');
const result = poker.opponentAggressionFactor(1, 1, 7, 5);
console.log(result);
```
