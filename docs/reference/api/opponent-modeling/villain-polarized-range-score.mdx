# `villainPolarizedRangeScore`
Score how polarized a villain range is.
<div className="apiSignature">{`villainPolarizedRangeScore(range: SparseRangeSpec | Float64Array, board: CardInput): number`}</div>
See [Packed card input](/docs/concepts/packed-card-input) and [SparseRangeSpec](/docs/reference/types/sparse-range-spec) where those inputs apply.

```js
const poker = require('poker-calculations');
```

## When to use
Use `villainPolarizedRangeScore` when you need to score how polarized a villain range is.

## How to use
```js

const result = poker.villainPolarizedRangeScore(1, 1, 7, 5);
console.log(result);
```
