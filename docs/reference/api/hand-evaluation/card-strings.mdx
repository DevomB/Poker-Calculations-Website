# Card strings

<ApiFamilyHeader category="Hand evaluation" suit="♠" functions={["parseCompactCardList","validateCardString","canonicalCardString","cardStringsHaveDuplicate"]} />

## `parseCompactCardList` \{#parseCompactCardList\}
Parse concatenated or whitespace-separated cards (`AhKh`, `Ah Kh`, `10hKd`); throws on invalid token or duplicate cards. Default `outFormat: 'strings'`; use `'packed'` for `Uint8Array` deck ids.

```ts
parseCompactCardList(text: string, options?: ParseCompactCardListOptions): string[];
parseCompactCardList(
  text: string,
  options: { outFormat: 'packed' }
): Uint8Array;
```

<details>
<summary>Types: <code>ParseCompactCardListOptions</code>, <code>ParseCompactCardListFormat</code></summary>

```ts
interface ParseCompactCardListOptions {
  outFormat?: ParseCompactCardListFormat;
}

/** Optional flags for `compareBestHands`. */

type ParseCompactCardListFormat = 'strings' | 'packed';
```


</details>

Use when importing compact hand histories or HUD paste buffers instead of splitting strings yourself. Use packed output when feeding Monte Carlo or strength helpers directly.

```js title="Example"
const poker = require('poker-calculations');

const cards = poker.parseCompactCardList('AhKh QdJc');
console.log(cards); // ['Ah','Kh','Qd','Jc'] canonical forms

const packed = poker.parseCompactCardList('AhKh QdJc', { outFormat: 'packed' });
const equity = poker.simulateHandOutcome(
  packed.subarray(0, 2),
  packed.subarray(2),
  10_000,
  42,
  1
);
```

```text title="Output"
[ 'Ah', 'Kh', 'Qd', 'Jc' ]
```

## `validateCardString` \{#validateCardString\}
`true` if `card` parses as a single card (`Ah`, `10c`, …).

```ts
validateCardString(card: string): boolean;
```

Use at form boundaries before calling evaluators or simulators—cheaper than try/catch on heavier APIs.

```js title="Example"
const poker = require('poker-calculations');
for (const input of ['Ah', '10c', 'Td', 'Zz', 'A']) {
  console.log(input, poker.validateCardString(input));
}
```

```text title="Output"
Ah true
10c true
Td true
Zz false
A false
```

## `canonicalCardString` \{#canonicalCardString\}
Canonical two-character form (`Th`, `Ac`, …); throws if invalid.

```ts
canonicalCardString(card: string): string;
```

Use to normalize user input (`10h` → `Th`) before storage or deduplication.

```js title="Example"
const poker = require('poker-calculations');
console.log(poker.canonicalCardString('10h'), poker.canonicalCardString('Td'));
```

```text title="Output"
Th Td
```

## `cardStringsHaveDuplicate` \{#cardStringsHaveDuplicate\}
`true` if any two entries map to the same card. Throws if any entry is invalid. Accepts `string[]` or packed `Uint8Array` (deck ids 0..51).

```ts
cardStringsHaveDuplicate(cards: CardInput): boolean;
```

Use before simulations or comparisons when cards come from user input or multiple sources.

```js title="Example"
const poker = require('poker-calculations');
console.log(poker.cardStringsHaveDuplicate(['Ah', 'Kd', 'Ah'])); // true
```

```text title="Output"
true
```
