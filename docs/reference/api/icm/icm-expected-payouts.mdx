# ICM payouts

<ApiFamilyHeader category="ICM" suit="♥" functions={["icmExpectedPayouts","icmExpectedPayoutsWeitzman","icmHarvilleSkillAdjustedPayouts"]} />

## `icmExpectedPayouts` \{#icmExpectedPayouts\}
ICM expected payouts (prize vector length = players).

```ts
icmExpectedPayouts(
  stacks: F64VectorInput,
  payouts: F64VectorInput,
  returnFormat?: F64ReturnFormat
): number[] | Float64Array;
```

Convert stacks and a **fixed payout ladder** into expected dollar (or chip) equity per seat—deal making, bubble pressure, and `icmPairwiseBubbleFactor` all build on this vector.

```js title="Example"
const poker = require('poker-calculations');

const stacks = [10000, 7500, 5000, 2500];
const payouts = [5000, 3000, 1500, 500];

const ev = poker.icmExpectedPayouts(stacks, payouts);
console.log(ev); // expected prize per player; sum ≈ sum(payouts)

console.log(poker.icmWinProbabilitiesHarville(stacks));
```

```text title="Output"
[
  3296.031746031746,
  2882.7380952380954,
  2320.6349206349205,
  1500.595238095238
]
[ 0.4, 0.3, 0.2, 0.1 ]
```

## `icmExpectedPayoutsWeitzman` \{#icmExpectedPayoutsWeitzman\}
Independent Weitzman chip-utility ICM (`alpha` defaults to 2).

```ts
icmExpectedPayoutsWeitzman(
  stacks: F64VectorInput,
  payouts: F64VectorInput,
  alpha?: number,
  returnFormat?: F64ReturnFormat
): number[] | Float64Array;
```

**Not Harville placement.** Splits each prize tier independently using chip utility `stack^alpha` (default `alpha = 2`). Use when you want a Weitzman-style model instead of [`icmExpectedPayouts`](/docs/reference/api/icm/icm-expected-payouts#icmExpectedPayouts) Harville math.

```js title="Example"
const poker = require('poker-calculations');
const stacks = [5000, 3000, 2000];
const payouts = [500, 300, 200];
console.log(poker.icmExpectedPayouts(stacks, payouts).map((x) => x.toFixed(1)));        // Harville
console.log(poker.icmExpectedPayoutsWeitzman(stacks, payouts).map((x) => x.toFixed(1))); // Weitzman, alpha = 2
```

```text title="Output"
[ '383.9', '327.5', '288.6' ]
[ '657.9', '236.8', '105.3' ]
```

## `icmHarvilleSkillAdjustedPayouts` \{#icmHarvilleSkillAdjustedPayouts\}
Harville ICM expected payouts when **first-place weights** blend chip share and a skill vector before placement recursion.

```ts
icmHarvilleSkillAdjustedPayouts(
  stacks: F64VectorInput,
  payouts: F64VectorInput,
  skillWeights: F64VectorInput,
  blend: number,
  returnFormat?: F64ReturnFormat
): number[] | Float64Array;
```

You want Harville ICM $EV with **skill-tilted** first-place probabilities — for study models, custom rating overlays, or comparing standard ICM to a skill-adjusted line.

```js title="Example"
const poker = require('poker-calculations');

const stacks = [12000, 8000, 5000, 2000];
const payouts = [10000, 6000, 3000, 1000];
const skillWeights = [1, 1, 0.5, 0.5];

const icm = poker.icmExpectedPayouts(stacks, payouts);
const adjusted = poker.icmHarvilleSkillAdjustedPayouts(stacks, payouts, skillWeights, 0.3);

console.log('Standard ICM seat 0:', icm[0]);
console.log('Skill-adjusted seat 0:', adjusted[0]);
```

```text title="Output"
Standard ICM seat 0: 6983.083912991033
Skill-adjusted seat 0: 6691.511027965358
```

`stacks`, `payouts`, and `skillWeights` must have the same length; stacks must be positive; skill weights must be non-negative with a positive sum.

**Returns** Length-`n` vector of expected payouts (`number[]` or `Float64Array` with `returnFormat: 'float64'`).
