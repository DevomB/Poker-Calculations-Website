## Conventions

- **Cards** are strings like `'Ah'` or `'Td'`, or packed deck ids in a `Uint8Array`. See [Card notation](/docs/concepts/card-notation) and [Packed card input](/docs/concepts/packed-card-input).
- **Ranges** are 1326 weights, dense (`Float64Array(1326)`) or sparse. See [Sparse range input](/docs/concepts/sparse-range-input).
- **Pots**: `pot` / `potBeforeCall` is everything in the middle when hero acts, villain's bet included. See [Numerical semantics](/docs/concepts/numerical-semantics#pot-convention-chip-math).
- **Errors** are thrown as ordinary JavaScript `Error`s; see [Errors and validation](/docs/concepts/errors-and-validation).
- **`*Async` functions** run on the libuv thread pool and accept an optional `{ signal }` to cancel.

## `poker-calculations/encode`

Six pure-JS helpers ship on an optional subpath: `packCards`, `unpackCards`, `cardStringToDeckIndex`, `deckIndexToCardString`, `packPokerState`, `unpackPokerState`. See [Packed card input](/docs/concepts/packed-card-input#helpers-poker-calculationsencode) and [Packed poker state](/docs/concepts/packed-poker-state#encodejs-helpers).
