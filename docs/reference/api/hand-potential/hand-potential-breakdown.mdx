## `handPotentialBreakdown` \{#handPotentialBreakdown\}

HS, PPot, NPot, EHS, EHS2, and weighted ahead/tied/behind masses in one pass.

```ts
handPotentialBreakdown(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range: Float64Array | SparseRangeSpec,
  options?: { streets?: 1 | 2 }
): HandPotentialBreakdown;
```

<details>
<summary>Types: <code>HandPotentialBreakdown</code></summary>

```ts
interface HandPotentialBreakdown {
  hs: number;
  ppot: number;
  npot: number;
  ehs: number;
  ehs2: number;
  nBehind: number;
  nAhead: number;
  nTied: number;
}

/** `comboEhsTableVsRange` options. `trials: 0` / omitted = exact next-street enumeration. */
```


</details>

Every hand-potential number for one spot in a single pass. Against a uniform range this reproduces the worked example in Billings et al. (A♦Q♣ on 3♥4♣J♥).

```js title="Example"
const poker = require('poker-calculations');
const range = new Float64Array(1326).fill(1); // every combo
const p = poker.handPotentialBreakdown(['Ad', 'Qc'], ['3h', '4c', 'Jh'], range);
console.log({ hs: p.hs.toFixed(3), ppot: p.ppot.toFixed(3), npot: p.npot.toFixed(3), ehs: p.ehs.toFixed(3) });
```

```text title="Output"
{ hs: '0.585', ppot: '0.108', npot: '0.145', ehs: '0.545' }
```

## `handStrengthVsRange` \{#handStrengthVsRange\}

Hand strength vs a villain range on this flop/turn: P(ahead) + 0.5 P(tie) if the hand ended now. Ties follow the HU chop (half). Blocked combos are removed.

```ts
handStrengthVsRange(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range: Float64Array | SparseRangeSpec
): number;
```

```js title="Example"
const poker = require('poker-calculations');
const range = new Float64Array(1326).fill(1); // every combo
console.log(poker.handStrengthVsRange(['Ad', 'Qc'], ['3h', '4c', 'Jh'], range).toFixed(3));
```

```text title="Output"
0.585
```

## `positivePotentialVsRange` \{#positivePotentialVsRange\}

One-card PPot (flop→turn or turn→river). `P(behind now and ahead later) / P(behind now)` with half-chop ties.

```ts
positivePotentialVsRange(
  heroHoleCards: CardInput,
  boardCards: CardInput,
  range: Float64Array | SparseRangeSpec
): number;
```

```js title="Example"
const poker = require('poker-calculations');
const range = new Float64Array(1326).fill(1); // every combo
// Chance a hand that is behind now gets ahead on the turn
console.log(poker.positivePotentialVsRange(['Ad', 'Qc'], ['3h', '4c', 'Jh'], range).toFixed(3));
```

```text title="Output"
0.108
```
