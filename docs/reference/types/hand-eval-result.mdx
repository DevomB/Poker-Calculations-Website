# HandEvalResult

Return type of [`evaluateBestHand`](/docs/reference/api/hand-evaluation/evaluate-best-hand#evaluateBestHand) when `format` is omitted or `'full'`.

| Field | Type | Meaning |
| --- | --- | --- |
| `rank` | `string` | Category label (`twoPair`, `flush`, …) — interned at module load; see [hand rank labels](/docs/concepts/hand-rank-labels) |
| `rankCategory` | `number` | Integer `0..9` — same order as [`handRankCategoryOrder`](/docs/reference/api/hand-evaluation/evaluate-best-hand#handRankCategoryOrder) |
| `strength` | `number` | Encoded strength — same bit layout as [`evaluateHandStrength`](/docs/reference/api/hand-evaluation/evaluate-hand-strength#evaluateHandStrength) |
| `kickers` | `number[]` | Five encoded kicker values for tie-breaking within the category |

For category + strength only (no `rank` string or `kickers` array), pass `{ format: 'slim' }` — see [`HandEvalResultSlim`](/docs/reference/types/hand-eval-result-slim).

For category label only (no kickers), use [`evaluateHandCategory`](/docs/reference/api/hand-evaluation/evaluate-best-hand#evaluateHandCategory).
