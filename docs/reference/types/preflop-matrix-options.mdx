# `PreflopMatrixOptions`

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `iterations` | `number` | `5000` | Monte Carlo trials per hand-class matchup |
| `seed` | `number` | `1` | Seed for the matrix's random number generator |
| `threads` | `number` | — | **Deprecated, ignored.** The matrix is computed on the calling thread; run it in a Worker to keep the main thread free. |

Passed to [`buildPreflopEquityMatrix`](/docs/reference/api/monte-carlo/preflop-equity-matrix#buildPreflopEquityMatrix).
