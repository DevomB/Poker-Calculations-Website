# `CardRemovalGradientResult`

Returned by [`exactEquityCardRemovalGradient`](/docs/reference/api/runout-analysis/card-removal#exactEquityCardRemovalGradient) and [`exactEquityCardRemovalGradientAsync`](/docs/reference/api/runout-analysis/card-removal#exactEquityCardRemovalGradientAsync).

| Field | Type | Meaning |
| --- | --- | --- |
| `gradient` | `Float64Array` | Length **52** — sensitivity per deck index |
| `baseEquity` | `number` | Hero equity vs range at current dead cards |

## Semantics

For each deck index `d` not already dead (hero, board, blockers), `gradient[d] = baseEquity - equity(d)`, where `equity(d)` is exact HU equity vs the range after additionally removing card `d` from the deck. Positive values mean equity **drops** when that card is dead (typical for cards that improve villain combos).

Blocked or already-dead indices are `0`. Contrast with the heuristic [`equityDeltaIfCardRemoved`](/docs/reference/api/runout-analysis/card-removal#equityDeltaIfCardRemoved), which uses Monte Carlo.

## Example

```js
const poker = require('poker-calculations');

// A small range on the turn keeps the exact enumeration fast
const range = poker.rangeFromNotationWeights([
  { notation: 'KK', weight: 1 },
  { notation: 'QQ', weight: 1 },
  { notation: 'AJs', weight: 1 },
]);

const { gradient, baseEquity } = poker.exactEquityCardRemovalGradient(
  ['Ah', 'Kh'],
  ['Qh', 'Jh', '2c', '7s'],
  range,
);
console.log({ baseEquity: baseEquity.toFixed(4), ifAcIsDead: gradient[48].toFixed(4) });
```

```text title="Output"
{ baseEquity: '0.3084', ifAcIsDead: '0.0061' }
```
