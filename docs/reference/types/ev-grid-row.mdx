# `EvGridRow`

One row of a bet-sizing EV grid from exports such as [`cbetSizeEvGrid`](/docs/reference/api/sizing-and-commitment/cbet-size-ev-grid).

## Shape

```ts
interface EvGridRow {
  betSize: number;
  foldFrequency: number;
  equityWhenCalled: number;
  ev: number;
}
```
