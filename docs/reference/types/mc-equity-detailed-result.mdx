# `McEquityDetailedResult`

Returned by [`simulateHandOutcomeDetailed`](/docs/reference/api/monte-carlo/simulate-hand-outcome#simulateHandOutcomeDetailed); [`simulateEquityVsRanges`](/docs/reference/api/monte-carlo/simulate-equity-vs-range#simulateEquityVsRanges) adds `attempts`.

| Field | Type | Meaning |
| --- | --- | --- |
| `estimate` | `number` | Mean equity share |
| `se` | `number` | Standard error from the sampled payoff variance (0.5 when `n` is 1) |
| `ciLow` | `number` | 95% Wilson score interval at the mean, low |
| `ciHigh` | `number` | 95% Wilson score interval at the mean, high |
| `n` | `number` | Trials run |

Split pots make each trial's payoff fractional, so these are not binomial formulas. See [Numerical semantics](/docs/concepts/numerical-semantics#detailed-monte-carlo-intervals).
