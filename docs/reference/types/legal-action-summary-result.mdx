# `LegalActionSummaryResult`

Legal action flags and raise bounds from [`legalActionSummary`](/docs/reference/api/bots/legal-actions#legalActionSummary).

## Shape

```ts
interface LegalActionSummaryResult {
  canFold: boolean;
  canCheck: boolean;
  canCall: boolean;
  canRaise: boolean;
  toCall: number;
  minRaiseTo: number;
  maxRaiseTo: number;
  actingIndex: number;
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `canFold`, `canCheck`, `canCall`, `canRaise` | Legal actions for the acting player. All false once the hand is over, or for a folded or all-in player. |
| `toCall` | Chips needed to call. It may exceed the stack, in which case a call is all-in. |
| `minRaiseTo` | Smallest legal raise **total**: the current bet plus the last full raise, or all-in when the stack is shorter. Formed in 64-bit integers, so large chip counts do not overflow. |
| `maxRaiseTo` | Largest raise total: all-in. |
| `actingIndex` | Index of the player these flags describe (player 0 when the state's `actingIndex` is -1). |

Raising needs another player still in the hand with chips; against opponents who are all in, the choices are call (or check) and fold. A player who already acted and faces less than a full raise (a short all-in) cannot re-raise.
