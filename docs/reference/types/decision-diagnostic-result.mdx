# `DecisionDiagnosticResult`

Combined policy output from [`decideActionWithDiagnostics`](/docs/reference/api/strategy/decide-action-with-diagnostics): decision, legality, optional EV breakdown, and reason or error.

## Shape

```ts
interface DecisionDiagnosticResult {
  decision: DecisionResult;
  legalActions: LegalActionSummaryResult;
  ev?: ActionEvBreakdownResult;
  reason: string;
  error?: string;
}
```
