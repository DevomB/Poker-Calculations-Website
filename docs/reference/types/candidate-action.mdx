# `CandidateAction`

One legal or candidate action with an optional raise amount from [`candidateActionSet`](/docs/reference/api/strategy/candidate-action-set).

## Shape

```ts
interface CandidateAction {
  action: 'fold' | 'check' | 'call' | 'raise';
  amount: number;
}
```
