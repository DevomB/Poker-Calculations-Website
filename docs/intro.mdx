# Poker Calculations

**poker-calculations** is poker math for Node.js: hand evaluation, Monte Carlo and exact equity, pot odds and chip EV, ICM and bounties, solvers, and a rule-based `decideAction` bot layer. Hold'em comes first, with Omaha (Hi, Hi-Lo, Big O), short deck, stud, razz, and 2-7 alongside. It is written in C++20 and ships prebuilt binaries for Linux, macOS, and Windows, so `npm install` needs no compiler.

```bash
npm install poker-calculations
```

## What people build with it

- Equity calculators and training tools
- Simulators and bots, tuned through `decideAction`
- Tournament tools: ICM, bubble factors, deals, bounties
- Study backends and research pipelines (wrap it in your own API; the package has no HTTP layer)
