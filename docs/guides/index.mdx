# Guides

Walkthroughs that follow one spot from start to finish. Every code block runs as written, and the output shown under it is what it printed.

| Guide | What you will do |
| --- | --- |
| [Monte Carlo equity](/docs/guides/monte-carlo-equity) | Estimate equity sync, async, or threaded, and cancel a long run. |
| [Range equity (exact)](/docs/guides/range-equity-exact) | Put a hand against a weighted range and get the exact answer, then check it with Monte Carlo. |
| [ICM & side pots](/docs/guides/icm-and-side-pots) | Price a final table, a bubble call, a deal, and a multiway all-in with side pots. |
| [Preflop equity matrix](/docs/guides/preflop-equity-matrix) | Build every 169 × 169 preflop matchup once and look any of them up. |
| [Batch equity](/docs/guides/batch-equity) | Evaluate many spots in one native call. |
| [decideAction](/docs/guides/decide-action) | Drive a rule-based bot from a table snapshot, with diagnostics and PKST bytes. |
| [Tournament, runouts, and bots](/docs/guides/tournament-runouts-and-bots) | Runout equity spread, deal math, and the cost of not seeing the future. |
