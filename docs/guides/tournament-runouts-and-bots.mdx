Three tools that come up in tournament software, study backends, and `decideAction`-style bots: how equity spreads across runouts, how a deal compares with ICM, and how much a range-aware decision gives up by not seeing the future.

## 1. Runout equity spread (`exactHeroEquityRunoutQuantiles`)

Mean equity on a draw-heavy flop hides bad runouts. Enumerate all turn/river completions and read the distribution:

```js
const poker = require('poker-calculations');

const hero = ['Ah', 'Kh'];
const flop = ['Qh', 'Jh', '2c'];

const q = poker.exactHeroEquityRunoutQuantiles(hero, flop);
console.log(q);
// { mean, variance, p05, p50, p95, n }
```

```text title="Output"
{
  mean: 0.7633009091843457,
  variance: 0.06401584999032402,
  p05: 0.36414141414141415,
  p50: 0.8767676767676768,
  p95: 1,
  n: 1081
}
```

Use `exactHeroEquityRunoutQuantilesAsync` when you pass a weighted villain range or need a non-blocking call in a server.

## 2. Deal math (`icmChopSurplusVsEqualSplit`)

When players negotiate a deal, compare what each seat gets from ICM with an equal split. The surplus shows who gives up equity by agreeing to chop evenly:

```js
const stacks = [12000, 8000, 5000, 2000];
const payouts = [10000, 6000, 3000, 1000];

const icm = poker.icmExpectedPayouts(stacks, payouts);
const surplus = poker.icmChopSurplusVsEqualSplit(stacks, payouts);
console.log(icm.map((x) => Math.round(x)));
console.log(surplus.map((x) => Math.round(x)));
```

```text title="Output"
[ 6983, 5848, 4583, 2587 ]
[ 1983, 848, -417, -2413 ]
```

For a full comparison of ICM, chip chop, and equal split in one call, use [`icmChopNegotiationAnalysis`](/docs/reference/api/icm/deals-and-chops#icmChopNegotiationAnalysis).

## 3. Information regret on one street (`exactInformationRegretVsClairvoyant`)

Measure how much call/fold EV you give up when you only see the current board, not the final runout, against a weighted range:

```js
const range = new Float64Array(1326);
range.fill(1 / 1326);

const regret = poker.exactInformationRegretVsClairvoyant(
  ['Ah', 'Kh'],
  ['Qh', 'Jh', '2c'],
  range,
  100,
  50
);
console.log('EV gap (chips):', regret);
```

```text title="Output"
EV gap (chips): 0.060269670079506454
```
