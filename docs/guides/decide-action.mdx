---
title: decideAction guide
---

Rule-based action from serialized table state, Monte Carlo equity (or strength fallback when sim count is 0), pot odds, and call EV.

## State shape

See [NativePokerState](/docs/reference/types/native-poker-state). You may pass PKST `Uint8Array` from [`encodePokerState`](/docs/reference/api/strategy/encode-poker-state) or [`packPokerState`](/docs/concepts/packed-poker-state) instead of a live object—see [Packed poker state](/docs/concepts/packed-poker-state).

| Field | Required | Notes |
| --- | --- | --- |
| `players[]` | yes | Each player needs `holeCards: CardInput` (`string[]` or packed `Uint8Array`) |
| `communityCards` | yes | Board cards (`CardInput`) |
| `phase` | yes | `preflop`, `flop`, `turn`, `river`, `showdown`, `handcomplete` (case variants accepted) |
| `actedThisStreet` | yes | One boolean per player |
| `pot`, `currentBet`, blinds, seats | optional | Table geometry |

**Hero seat:** pass `heroSeat` explicitly, or the engine uses the acting player's seat, or seat `0`.

## Config

See [NativeBotConfig](/docs/reference/types/native-bot-config) and optional [NativeOpponentModel](/docs/reference/types/native-opponent-model).

[`normalizeBotConfig`](/docs/reference/api/strategy/normalize-bot-config) fills missing fields and clamps values before you call policy exports.

When `monteCarloSimulations` is `0`, strategy falls back to encoded hand strength instead of simulated equity.

## Example

```js
const poker = require('poker-calculations');

const state = {
  players: [
    {
      name: 'Hero',
      holeCards: ['Ah', 'Kh'],
      stack: 200,
      committedThisStreet: 0,
      seat: 0,
    },
    {
      name: 'Villain',
      holeCards: ['Qc', 'Qd'],
      stack: 180,
      committedThisStreet: 10,
      seat: 1,
    },
  ],
  communityCards: ['Qh', 'Jh', '2c'],
  phase: 'flop',
  pot: 30,
  currentBet: 10,
  smallBlind: 1,
  bigBlind: 2,
  buttonSeat: 0,
  actingIndex: 0,
  actedThisStreet: [false, true],
};

const config = {
  monteCarloSimulations: 2000,
  monteCarloVillains: 1,
  rngSeed: 42,
};

const decision = poker.decideAction(state, config, null, 0);
console.log(decision.action, decision.raiseBy);
```

## Non-blocking and cancellation

[`decideActionAsync`](/docs/reference/api/strategy/decide-action-async) runs the same logic on the libuv thread pool. When `monteCarloSimulations > 0`, pass [`AsyncOptions`](/docs/reference/types/async-options) to abort in-flight Monte Carlo:

```js
const ac = new AbortController();
const pending = poker.decideActionAsync(state, config, null, 0, { signal: ac.signal });
// ac.abort(); // Promise rejects with AbortError
const decision = await pending;
```

## Diagnostics and EV breakdown

| Export | Use when |
| --- | --- |
| [`decideActionWithDiagnostics`](/docs/reference/api/strategy/decide-action-with-diagnostics) | You need the chosen action plus legal actions, EV breakdown, and a reason string in one call. Returns [`DecisionDiagnosticResult`](/docs/reference/types/decision-diagnostic-result). |
| [`actionEvBreakdown`](/docs/reference/api/strategy/action-ev-breakdown) | You want fold/check/call/raise EV and equity without committing to a single action. Returns [`ActionEvBreakdownResult`](/docs/reference/types/action-ev-breakdown-result). |
| [`explainDecisionFactors`](/docs/reference/api/strategy/explain-decision-factors) | You need ranked human-readable factors behind a policy choice. Returns [`DecisionFactor`](/docs/reference/types/decision-factor) rows. |

## Validation and legal actions

| Export | Use when |
| --- | --- |
| [`validatePokerState`](/docs/reference/api/strategy/validate-poker-state) | Pre-flight a snapshot before simulation or policy runs. Returns [`PokerStateValidationResult`](/docs/reference/types/poker-state-validation-result). |
| [`legalActionSummary`](/docs/reference/api/strategy/legal-action-summary) | You need raise bounds and which actions are legal. Returns [`LegalActionSummaryResult`](/docs/reference/types/legal-action-summary-result). |
| [`candidateActionSet`](/docs/reference/api/strategy/candidate-action-set) | Build a discrete action menu with raise sizes. Returns [`CandidateAction`](/docs/reference/types/candidate-action) rows. |
| [`actionMaskFromState`](/docs/reference/api/strategy/action-mask-from-state) | Encode legality as a compact bitmask for ML or fast filters. |
